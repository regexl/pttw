1直言命题基础

什么是直言命题

直言命题（又称性质命题）是直接断定对象具有或不具有某种性质的简单命题。它一句话直接判断，不带"如果""或者""并且"等连接词。

核心定义
直言命题 = 直接断定 S 和 P 之间是否有关系的命题，是逻辑判断中最基础的命题类型。

直言命题的四要素结构

每一句标准直言命题都由四个部分组成：

【量项】 + 【主项 S】 + 【联项】 + 【谓项 P】
要素含义示例（所有学生都是努力的）
量项表示数量范围所有 / 有的 / 某个
主项 S被断定的对象学生
联项表示肯定或否定是 / 不是
谓项 P对象的性质努力的

直言命题的六大分类

按量项（所有/有的/某个）和联项（是/不是）组合，共六种标准形式：

代号类型标准形式示例
A全称肯定所有 S 都是 P所有同学都及格了
E全称否定所有 S 都不是 P所有同学都没及格
I特称肯定有的 S 是 P有的同学及格了
O特称否定有的 S 不是 P有的同学没及格
a单称肯定某个 S 是 P小明及格了
e单称否定某个 S 不是 P小明没及格
记忆口诀
全称 = 全部（所有）；特称 = 部分（有的）；单称 = 个体（某个）。A/E/I/O 四个代号来自拉丁语 Affirmo（我肯定）和 Nego（我否定）的元音字母。

直言命题 vs 复言命题

类型特征示例
直言命题单句直接判断性质，无连接词所有学生都努力
联言命题A 且 B小明努力且聪明
选言命题A 或 B / 要么 A 要么 B要么及格，要么不及格
假言命题如果 A 那么 B（A→B）如果努力，那么及格

2特称命题详解

"有的"在逻辑中的精确含义

这是行测逻辑中最容易踩坑的概念。日常生活中"有的"常被理解为"一部分"，但在形式逻辑中：

高频易错点
逻辑中的"有的" = 至少有一个，不等于"一部分是、一部分不是"。

以下三种情况都满足"有的 S 是 P"：

实际情况"有的 S 是 P""有的 S 不是 P"
只有 1 个 S 是 P真真
一部分是、一部分不是真真
全部 S 都是 P真假
关键推论
由"有的同学及格了"无法推出"有的同学没及格"！因为可能全部都及格了。

特称命题的两种形式

I 命题
有的 S 是 P
特称肯定
O 命题
有的 S 不是 P
特称否定

3传统逻辑方阵（对当方阵）

什么是逻辑方阵

传统逻辑方阵（又称对当方阵）是一张正方形示意图，源自亚里士多德传统逻辑，系统整理了四种标准直言命题（A/E/I/O）之间的真假制约关系。行测真假推理的全部考点都出自这张图。

生效前提
方阵中的四个命题必须主项 S 和谓项 P 完全一致（同一主体、同一话题），否则不能套用任何关系。

方阵四条边的关系

位置关系名称涉及命题真假规则
上边上反对A ↔ E（两个所有）不能同真，可以同假，必有一假
下边下反对I ↔ O（两个有的）不能同假，可以同真，必有一真
对角线矛盾A↔O、E↔I必有一真一假，不能同真同假
左右竖边差等A→I、E→O上真下必真，下假上必假
为什么叫"上/下反对"？
传统方阵中"所有"在上方、"有的"在下方。上方一组 = 上反对，下方一组 = 下反对。

4矛盾关系

矛盾关系的定义

矛盾关系是指两个命题非此即彼，没有第三种可能。满足：

不能同真 + 不能同假 → 必有一真、必有一假
集合视角
矛盾 = 互斥（交集为空）+ 并集为全集（穷尽所有情况）。两者加起来 = 全部范围。

直言命题中的四组矛盾

命题一命题二关系真假
所有 S 是 P（A）有的 S 不是 P（O）矛盾一真一假
所有 S 不是 P（E）有的 S 是 P（I）矛盾一真一假
某个 S 是 P（a）某个 S 不是 P（e）矛盾一真一假

矛盾 ≠ 互斥（反对）

这是最核心的区分。很多人以为"不能同时为真就是矛盾"，这是错误的！

关系能否同真能否同假有无中间情况
矛盾不能不能无（非此即彼）
上反对不能可以有（部分是部分不是）
下反对可以不能有
生活中的对比
矛盾：男 vs 非男（包含女及其他，穷尽全部）
反对：男 vs 女（还有第三种情况，未穷尽）
矛盾一定互斥，但互斥不一定是矛盾！

矛盾关系在做题中的用法

题干给出几句话，限定"只有一真"或"只有一假"时：

解题套路
找到矛盾的两句话 → 锁定一真一假在其中
若题干"只有一真" → 真话在矛盾中，其余句子全为假
若题干"只有一假" → 假话在矛盾中，其余句子全为真
由其余句子的真假推出最终答案

5上反对关系

上反对的定义与规则

上反对关系指两个全称命题之间的关系：

所有 S 是 P（A） ↔ 所有 S 不是 P（E）
核心规则
必有一假 —— 不能同真，可以同假。

三种现实情况验证

以"所有同学及格" vs "所有同学不及格"为例：

实际情况所有都及格（A）所有都不及格（E）特征
全部及格真假一真一假
全部不及格假真一真一假
部分及格、部分不及格假假同假

三种情况中，A 和 E 从未同时为真，但可以同时为假 → 必有一假。

上反对的做题应用

典型配对
上反对（必有一假）最适合题干限定"只有一句话为真"的场景。

原理：两句中至少一个是假话 → 唯一真话不在这一组 → 剩下的那句话必然为真。

真题模板示例

关于班级考试，三句话：

① 所有人都及格了（A）
② 所有人都没及格（E）
③ 小明及格了

已知：三句中只有 1 句真话

①② 构成上反对 → 必有一假
总共只有 1 句真话 → 真话不在①② → ③必然为假
③假 → 小明没及格
小明没及格 → ②"所有人都没及格"为真，①为假
结论：全班都没及格

6下反对关系

下反对的定义与规则

下反对关系指两个特称命题之间的关系：

有的 S 是 P（I） ↔ 有的 S 不是 P（O）
核心规则
必有一真 —— 不能同假，可以同真。

三种现实情况验证

以"有的同学及格" vs "有的同学不及格"为例：

实际情况有的及格（I）有的不及格（O）特征
全部及格真假一真一假
全部不及格假真一真一假
部分及格、部分不及格真真同真

三种情况中，I 和 O 从未同时为假，但可以同时为真 → 必有一真。

下反对的做题应用

典型配对
下反对（必有一真）最适合题干限定"只有一句话为假"的场景。

原理：两句中至少一个是真话 → 唯一假话不在这一组 → 剩下的那句话必然为假。

真题模板示例

关于单位加班，三句话：

① 有的人需要加班（I）
② 有的人不需要加班（O）
③ 主任需要加班

已知：三句中只有 1 句假话

①② 构成下反对 → 必有一真
总共只有 1 句假话 → 假话不在①② → ③必然为假
③假 → 主任不需要加班
主任不加 → ②"有的人不需要加班"为真
结论：所有人都不用加班

7差等关系（推出关系）

差等关系的定义

差等关系是方阵左右两条竖边的关系，指全称命题与同质特称命题之间的推出关系：

A（所有是） → I（有的是）　　E（所有非） → O（有的非）
核心规则
上真下必真，下假上必假；反过来（上假/下真）则真假不定。

四种情况分析

已知推出结论示例
A 真（所有是）I 真（有的是）必真所有人及格 → 有人及格
I 假（有的是为假）A 假（所有是为假）必假没人及格 → 不是所有人及格
A 假（所有是为假）I 真假不定不定并非都及格 → 可能有人及格也可能都没
I 真（有的是）A 真假不定不定有人及格 → 不一定所有人都及格
注意
差等关系在行测中考频相对较低，通常作为矛盾/反对之后的辅助推理工具。

8真假推理题型解法

题型识别

上反对、下反对、矛盾关系都只出现在真假推理题中。题干特征：

  • 给出若干句话（通常 3-4 句）
  • 限定真假数量："只有一句真话"或"只有一句假话"
  • 要求根据条件推出结论

标准解题三步法

通用解题流程
第一步：找关系 —— 优先找矛盾关系；没有矛盾再找上反对/下反对；都没有再考虑差等（推出）关系
第二步：定范围 —— 根据关系口诀，划定真话/假话所在的范围
第三步：判其余 —— 判断除关系组之外的句子的真假，由此推出答案

三种关系的配对使用

关系句式组合核心规则高频题干限定做题结论
矛盾所有是↔有的非 等一真一假1真或1假均可其余全真/全假
上反对所有是 & 所有非必有一假只有 1 真其余为真
下反对有的是 & 有的非必有一真只有 1 假其余为假

做题优先级

① 矛盾关系
优先使用！对角线
一真一假锁定范围
② 上/下反对
没有矛盾时使用
两个所有 / 两个有的
③ 差等关系
辅助推理
所有推有的

完整真题演练

例题（上反对题型）

某单位共有 20 名员工：①有人是本科学历；②单位负责人不是本科学历；③有人不是本科学历。上述三个判断中只有一个是真的。

以下哪项正确表示了该单位具有本科学历的员工人数？

①"有人是本科"（I）和 ③"有人不是本科"（O）→ 下反对关系，必有一真
题干只有一真 → 真话在①③中 → ②必然为假
②假 → 单位负责人是本科学历
负责人是本科 → ①"有人是本科"为真
因为只有一真，①真则③假 → "有人不是本科"为假 → 所有人都是本科
结论：20 人都是本科学历

9易错点与陷阱

陷阱一：混淆矛盾和反对

错误认知
"不能同时为真 = 矛盾" —— 错！两个所有不能同真，但可以同假，这是上反对，不是矛盾。

矛盾的硬性标准：不能同真 AND 不能同假，两者缺一不可。

陷阱二：乱用反对口诀

关系适合题干不适合题干
上反对（必有一假）只有 1 真只有 1 假（优先找矛盾）
下反对（必有一真）只有 1 假只有 1 真（优先找矛盾）

陷阱三：主体/话题不一致

无效关系
"所有员工迟到"和"有的学生迟到" —— S 不一样（员工≠学生），不能构成任何反对或矛盾关系。

方阵所有关系的前提是：主项 S 和谓项 P 必须完全相同。

陷阱四：误解"有的"的含义

常见错误推理
由"有的同学及格了"推出"有的同学没及格" —— 错！因为可能全部都及格了。

逻辑中的"有的" = 至少一个，包含"全部"这种极端情况。

陷阱五：忽略单称命题

"某个 S 是 P"和"某个 S 不是 P"也是矛盾关系，在做题时不要遗漏。单称命题在真假推理中常作为"其余句子"出现，是推出答案的关键。

一句话终极总结

核心心法
真假推理三步走：先找矛盾，再看反对，最后差等。矛盾锁一真一假，上反对配"只有一真"，下反对配"只有一假"，其余句子定答案。
