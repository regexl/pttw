一、图形推理通用解题框架

总原则：先定性、后定量、再属性
图形推理的观察顺序是固定的，不要一上来就数点线面。绝大多数题在“看图两秒”内就能靠定性判断定方向，定性无解再进入定量。
  1. 一看图形组成：组成元素是否相同/相似？是“相同元素看位置”还是“不同元素看数量”。
  2. 二看位置特征：元素位置发生移动→位置规律（平移、旋转、翻转）；位置不动→排除位置。
  3. 三看数量特征：点（交点）、线（笔画/直曲线）、面（封闭区域）、素（元素种类/个数）。
  4. 四看属性特征：对称性（轴对称/中心对称）、曲直性、开闭性、黑白运算、加减同异。
  5. 五看特殊规律：样式运算（叠加）、元素替换、空间重构、立体截面。
图形组成相同 / 相似
  • 完全相同：优先看位置（平移、旋转、翻转），其次看样式运算（叠加）。
  • 相似（组成元素不变，细节有别）：优先看数量（交点数、线条数、封闭区域数），其次看属性（曲直性、开闭性）。
  • 凌乱无序：说明图形本身不构成规律，规律藏在选项里（见“极端思维”与排除法）。
题干特殊形式识别
  • 六图两问：分为两类，即“分类分组型”，考的是两类各自的共性，不是找唯一规律。
  • 问“不能/不属于”：反向问法，需先找出三项的共性，剩下的一项即为答案。
  • 问“最恰当/最符合”：选项之间存在风格差异，往往是数量递减、线条递增等程度类规律。
  • 题干给出图形分组：优先考虑对称性、曲直性、开闭性这三类属性二分法。

二、考点一：位置规律

识别特征：图形组成完全相同（元素个数、形状、大小一致），只是摆放位置不同 → 直接锁定位置规律。位置规律的本质是“谁在动、往哪动、动多少”。
平移规律

方法要点

  • 方向：上下、左右、斜向（左上→右下、右上→左下）。
  • 步长：可以是恒定步长，也可以是等差数列步长（如 1、2、3 格）。
  • 平移方式：
    • 直接平移：图形整体沿直线移动。
    • 平移+翻转：每步平移的同时自身翻面（如左右镜像交替）。
    • 循环平移：多个元素分别按不同方向/步长移动，需要逐个元素单独追踪。
  • 解题动作：选一个特征最明显的元素（尖角、缺口、阴影块）作为跟踪锚点，只跟一个元素即可锁定规律。
⚠️ 陷阱：多个元素移动方向不一致时，不要试图整体平移；改为分元素追踪，分别记方向与步长（常为等差）。
旋转规律
  • 识别：元素造型不变，只是朝向改变。
  • 方向：顺时针 / 逆时针（方向恒定最常见；方向交替是进阶考法）。
  • 角度：常见 90°、120°、135°、180°、45°；角度本身也可构成等差数列。
  • 叠加旋转：整体旋转 + 内部元素相对旋转（双层旋转），需要分别追踪外框和内元素。
  • 解题动作：找一条“参照边”（如直角边、斜边、指针方向），记录它每次转过的角度。
⚠️ 陷阱：60°、45° 易看错方向。方向判断错会导致全盘皆错，务必先用一个特征突出的元素确定顺/逆时针，再看角度。
翻转规律
  • 上下翻转（沿水平轴镜像）与左右翻转（沿垂直轴镜像）。
  • 翻转+平移：最常见的复合形式，尤其在图形不规则时。
  • 辨析翻转与旋转：翻转不改变图形内部的顺/逆时针环绕关系（会镜像），旋转保持环绕关系不变——用图形内部的小箭头/小元素朝向判断。
  • 解题动作：在图上标出左右两个方向的特征元素，看对应关系是否镜像。
⚠️ 陷阱：左右翻转看起来像“对称”，容易误判为对称规律。要区分：对称是同一个图形自身轴对称；翻转是图形 A 变成图形 B。
时针（指针式）规律
  • 本质是位置规律的一种：指针绕固定中心按一定角度、方向、周期转动。
  • 关注三要素：转动的指针数量（一根/多根）、方向（顺/逆）、步长角度（可等差）。
  • 多指针时，每根指针的步长可能不同，需分别记录。

三、考点二：数量规律 —— 面（封闭区域）

识别特征：图形组成元素不规则（不相似也不完全相同），但肉眼可见被分成若干块状封闭空间 → 数“面”。面的数量是图形推理中出现频率最高、最稳定的数量考点。
面的三种数法（关键区分）
数法定义典型说明与易错点
封闭区域数图形内部被线条完全围成的独立空白块数最常用。汉字、字母、图形拼接时，数“被围住的口”。注意外部的大空白不算面，只数被线段围出的封闭区域。
面数量（区域数，含轮廓外）在封闭区域基础上考虑整体轮廓当题干图形存在笔画交叉形成的区域时常用；关键判断是否把图形自身轮廓当作一条边界线。
部分数 / 拆分计数由几个独立的部分组成图形被明显分割成互不相连的块时数块数；注意“分离的笔画”也算部分。
面的常见数列规律
  • 等差：1、2、3、4、5（递增）或 5、4、3、2、1（递减）。
  • 恒定：每个图形都是 3 个面 / 4 个面。
  • 等比或倍数：1、2、4、8。
  • 分组数列：两两一组，如 1、2 / 3、4 / 5、6（每组差 1）。
  • 质数数列：2、3、5、7。
  • 图形间做加减：图1 + 图2 = 图3 的面数（前两项相加等于第三项）。
  • 面数量相同但形状不同：面数一致即规律成立，此时往往考面的形状组合。
面的易错陷阱
  • 数错闭合口：线条末端未闭合的地方不算一个面，须逐条确认边界闭合。
  • 忽略镂空：图形中间的“洞”是独立的面，容易漏数。
  • 忽略交叉产生的面：两条线交叉会额外增加区域。
  • 把图形外的空白计入：面只算图形内部封闭区域。
  • 混淆“笔画数”与“面数”：见后文线条部分。

四、考点二：数量规律 —— 点（交点）

识别特征：图形由线条（直线、曲线）构成，且线条之间存在大量交叉点 → 数“点”。点的规律通常等差，分 交点数 与 切点数 两类。
点的两大类型
  • 交点：线条与线条相交形成的点（直线交直线、直线交曲线、曲线交曲线都算交点）。
  • 切点：线条与线条相切（相接但不穿过）形成的点，常在两圆相切、线与圆相切中出现。
💡 计数时只数图形内部的点；图形轮廓线自身的外接顶点不算交点。
点的解题方法
  1. 先分类，再计数：区分交点与切点，确定题目考的是哪一种（通常只考交点，若切点明显则单独考虑）。
  2. 数“点”的位置优先级：从图形左上角开始，顺时针/逆时针逐个标记，避免漏数重数。
  3. 快速验数：直线交点数可用“线数×线数 − 重合数”粗估；圆形图形用切线弦定理式直觉（一条直线与圆相切时交点数骤减）。
  4. 找数列：交点数常呈 1、2、3、4 递增，或 2、3、5、7，或 5、4、3、2 递减。
点的易错陷阱
  • 把端点（线条起止点）当成交点——端点通常不算。
  • 曲线相切与相交的混淆。
  • 多个点重叠在同一位置（粗细线叠印），只算一个点。
  • 图形轮廓的四角顶点不算交点。

五、数量规律补充：线、角、素

线条数（笔画）
  • 直线数 / 曲线数：数图形中直线、曲线各自的条数，常一增一减。
  • 笔画数（一笔画/两笔画）：奇点（连接奇数条线的点）个数决定笔数。
    • 奇点 0 个 → 一笔画
    • 奇点 2 个 → 两笔画
    • 奇点 2n 个 → n 笔画
  • 解题方法：先数奇点个数（连接奇数条线的交点），奇点为 0/2 的一笔画两笔画最常考。
角度数
  • 图形中直角、锐角、钝角的个数，常呈等差或一增一减。
  • 注意区分图形内角与图形之间的夹角。
  • 与曲直性联动：一个图形全是直线 → 必有直角；含曲线则多为非直角。
元素种类与个数（素）
  • 种类数：图形由几种不同元素/图形拼成（常为 2、3、4 种）。
  • 个数：每种元素出现几次（常呈等差 1、2、3）。
  • 方法：先分类再计数；每种元素单独记数，再看每种的个数是否成规律。
曲直性 / 开闭性
  • 曲直性：全直线、全曲线、直曲结合（分类分组题高频考点）。
  • 开闭性：图形是开放图形（线条不封闭）还是封闭图形，常一条开一条闭交替。
  • 分类分组题中，这两项常作为第一层切分维度。

六、考点三：对称规律

识别特征：图形组成元素相似（甚至相同）但整体摆放形态各异，重点看其自身结构是否轴对称或中心对称。对称规律本身即答案，无需再找数量。
两大对称类型
  • 轴对称：沿某条直线折叠可完全重合。
    • 找轴的方法：看图形的最外轮廓与内部元素是否都对称；只外轮廓对称而内部不对称 → 不是轴对称。
    • 对称轴数量本身也可成为规律（1 条、2 条、无数条交替）。
  • 中心对称：绕某点旋转 180° 后与自身重合。
    • 判断技巧：图形内部若存在箭头、缺口、不对称小元素，中心对称时被“甩”到对侧位置，而不是原地保留。
    • 与轴对称的区别：一个图形可能只轴对称、只中心对称、两者兼具（如正方形、圆）或两者皆无（如一般不规则图形）。
解题方法与顺序
  1. 第一步：看题干图形是否有明显的对称元素（如带对称的字母、字母表镜像、规则多边形）。
  2. 第二步：若整体不对称，尝试部分对称——只取图形中的某一部分（如一个小箭头）判断其对称性。
  3. 第三步：分类分组题中，用“轴对称 / 非轴对称”或“中心对称 / 非中心对称”作二分切分，再验证二分类是否成立。
  4. 第四步：若四项答案对称性都相同，则对称不是规律，转看对称轴方向/数量或改看其他考点。
对称的易错陷阱
  • 只看外轮廓就判定轴对称，忽略内部元素不对称。
  • 把旋转 180°误当中心对（旋转的是整组图形之间的关系，对称说的是单个图形自身的性质）。
  • 把“看起来对称”当作“数学上对称”——对称轴必须贯穿图形并使两侧完全重合。

七、考点四：图形的“加减同异”

识别特征：题干中出现两个及以上简单图形叠加（如两个小图 + 一个问号框），或者图形之间存在覆盖、叠加、擦除关系 → 属于“样式运算/加减同异”类。核心是定义运算规则，而非寻找数量规律。
四类基本运算规则
规则含义说明
去同存异保留两者不同的部分，相同部分抵消最常见。判定方法：把前后两个图对应位置逐一比对，“黑黑白黑”类图形直接看某位置是否同时同色。
去异存同保留两者相同的部分，不同的抵消与去同存异恰好互补；两者常作为干扰项同时出现。
求同（叠加相同）相同部分保留并加粗，不同部分消失常见于线条图：相同线条保留、其余擦除。
差（相减）去同存异或叠加求差（异或型）常以“白+黑=黑”一类的布尔运算形式出现（见黑白运算）。
解题方法
  1. 找“两个图形叠加”的位置：常见为 “图1 + 图2 → ？” 或 “图1 = 图2 + 图3”。
  2. 优先选简单图形做试验：线条少的一方更容易看出叠加痕迹。
  3. 只验证一个特征点：不必整图比对，选线条最少的位置试推，若成立再推广到全图。
  4. 规则不确定时用选项反推：把四个选项分别与前两图试算，看哪种规则能自洽且唯一对应。
  5. 线条类叠加：注意“保留”还是“加粗”——相同线条叠加可能变粗，这是重要区分点。
易错陷阱
  • “去同存异”与“去异存同”选反——两者互为干扰项，务必用选项验证。
  • 把叠加结果理解为“颜色相加”（黑+黑=黑），忽略了图形是线条集合。
  • 叠加时未考虑图形被完全覆盖的情形。
  • 题干中图形有位置移动时，误判为叠加，实为位置规律（位置+样式复合题）。

八、考点五：黑白运算

识别特征：图形被网格（常见 3×3、4×4 或九宫格）分割，每个格子里有黑格/白格/空，图形之间呈现逐格对应的运算关系 → 黑白运算（也称“黑白块运算”“格内运算”）。
两大思路：位置类与数量类
  • 位置类（逐格对应运算）：把两个图按格位对齐，逐格考察黑白的进退关系，得出一个运算规则，再用第三图验证。
    • 常见规则：黑+黑=白（去同存异）、黑+白=黑（去异存同/异或）、白+白=白（或）、黑+黑=黑（或）、黑+白=白（与非）、相同得白、不同得黑（异或）等。
    • 关键：题目通常是三个图形（图1、图2、图3），图1 与图2 按规则运算得到图3；问号处由图2、图3 按同一规则推出。
  • 数量类：不逐格对齐，而是看整体黑格数量的加减关系（如 黑1 + 黑2 = 黑3，或 黑1 − 黑2 = 黑3）。
    • 适合图形整体黑白分布杂乱的题目，逐格对齐找不到规律时改用数量法。
    • 注意空格子的编码：空 = 0，白 = 1，黑 = 2，则运算可能变为纯加减。
解题方法
  1. 找对齐基准：以题干给定的图形边框/网格为参照，确保三个图按同一格位对应（不要凭视觉大小随意对齐）。
  2. 先做一格：随便挑一格，看两个已知图在该格的颜色组合与第三图的结果，推测规则。
  3. 横向验证：用推测规则检查全部格子是否自洽；只要有一格不成立，规则就错，需换规则重推。
  4. 常见规律速记表：黑+黑=白、白+白=白、黑+白=黑（异或型）；或型（全黑）；与非型（黑白相与为白）。
  5. 兜底策略：若位置法推不通，直接转数量法（黑格数相加/相减），通常能解。
易错陷阱
  • 对齐错位——两图大小不同却强行按视觉位置对齐，结论全错。
  • 把空格与白格混为一谈（很多题目刻意区分）。
  • 规则只在一两格成立就仓促定案，未做全格验证。
  • 位置法失败后仍死磕，浪费做题时间（应立刻转数量法或回头看其他考点）。

九、常用解题思维：极端思维

为什么需要它：当题干图形“看上去毫无规律”（元素杂乱、形状各异）时，规律往往不在题干序列里，而是题干与选项之间的差异。此时用极端思维：构造“最极端/最不可能”的选项，用排除法反推。
核心思想

不追求“找出规律”，而是先排除。极端思维指的是：把选项当作可能呈现的“极端形态”，观察哪些选项明显不符合图形的整体风格（数量跨度、元素属性、复杂程度），从而锁定答案。

  • 数量极端：题干图形复杂度接近，而某个选项元素数量明显偏多/偏少 → 排除。
  • 属性极端：题干全为封闭图形，某选项为开放图形 → 排除；题干全为轴对称，某选项明显不对称 → 排除。
  • 构成极端：题干图形均由若干相同小元素组成，某选项结构完全迥异 → 排除。
  • 视觉极端：某选项线条异常密集/异常稀疏，与题干视觉密度不匹配 → 排除。
落地步骤
  1. 先常规尝试：按位置→数量→属性顺序找规律，各给 5~10 秒。
  2. 无解则转极端：不看题干找规律，改为逐个选项与题干整体比对，找出“格格不入”的那一项。
  3. 反向选择题（问“不能/不属于”）：先找出三项的共性，剩下的即为答案——这是极端思维的典型应用。
  4. 分类分组题：把六个图两两比较，找“能配成对的那一组”，剩下的两项即为答案。
  5. 时间控制：一道图推 90 秒仍无头绪，果断标记跳过，回头再做。
极端思维在分类题中的用法
  • 六图分类的标准流程：先横看（同排/同组找共同属性）→ 再纵看（逐个过一遍四类属性：对称性、曲直性、开闭性、元素组成）→ 只要能干净地分成 3+3，规律即成立。
  • 常见易错点：找到“3+3”但其中某一组内部并不统一；此时应放弃该维度，换下一个维度再切。
  • 验证方法：把分好的两组分别再找一条共同解释，若两组解释不同但都成立，说明切分正确。

十、二级辨析与解题优先级

一级规律与二级辨析
  • 一级规律：位置、数量、属性、样式四大类，是解题的主框架。
  • 二级辨析：当一级规律有多个答案都能解释题干时，用更细的维度把答案唯一化。常见二级维度：
    • 数量规律：等差/等比/质数/分组/图形间加减；面数相同 → 继续看面的形状。
    • 位置规律：方向+步长之外，再看是否循环、是否叠加旋转。
    • 对称规律：轴对称/中心对称之外，再看对称轴方向、对称轴数量。
    • 样式规律：叠加规则之外，再看线条粗细、颜色深浅。
解题优先级速排（考场执行顺序）
优先级观察方向触发条件 / 判断依据
1位置元素完全相同，只是摆放不同 → 平移/旋转/翻转
2属性图形组成相似但形态各异，且选项中存在明显对称/曲直差异 → 对称、开闭、曲直
3数量-面图形被分成若干封闭块，肉眼可见“几个口”
4数量-点线条构成且交叉明显，数交点
5样式运算出现两个图叠加或图形擦除关系
6黑白运算网格 + 黑白格逐格对应
7极端思维以上全部无解 → 转向选项对比与排除
一眼定位口诀
  • 长得一样 → 动位置（平移、旋转、翻转）
  • 长得像 → 数数量（面、点、线、角、素）
  • 长得不像 → 看属性（对称、曲直、开闭）
  • 两图一起 → 做叠加（加减同异、黑白运算）
  • 都不像 → 走极端（选项排除法）

十一、考场速查卡

NUM-01
平移
方向 + 步长
跟一个特征元素；多元素分开跟；步长可等差。
NUM-02
旋转
顺/逆 + 角度
先定方向再定角度；注意 45°/60° 易错；双层旋转分层跟。
NUM-03
翻转
左右 / 上下
镜像会改变环绕关系；与旋转区分看内部小元素朝向。
NUM-04
面
封闭区域数
数“口”；镂空、交叉额外区域要算；外部空白不算。
NUM-05
点
交点 / 切点
端点不算；轮廓顶点不算；重合点只算一个。
NUM-06
线
笔画 / 曲直
奇点 0 → 一笔画；奇点 2 → 两笔画；曲直性常用于分组。
NUM-07
对称
轴 / 中心
内外都要对称才算；可只取部分元素判断。
NUM-08
叠加
去同存异 / 存同
选最简单图形试验；两规则互为干扰，必须用选项验证。
NUM-09
黑白
位置 / 数量
逐格对齐推规则并全格验证；失败转数量法（黑格加减）。
NUM-10
极端
排除法
题干无规律时，比对选项风格与数量跨度，排除突兀项。
时间分配建议
  • 单题目标用时 60~90 秒；图形题平均应控制在 70 秒 内。
  • 一图推不出，先做标记，不要在一题上耗过 2 分钟。
  • 做题顺序建议：先扫分类分组题（规律明确、耗时可控），再攻位置与数量规律，最后处理黑白运算与叠加。
  • 本讲义涉及考点（位置、面、点、对称、加减同异、黑白运算、极端思维）覆盖图形推理主干题型，练题时按考点专项突破，效率高于按套卷随机刷。
