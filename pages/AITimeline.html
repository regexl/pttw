三条贯穿主线

主线 1 · 模型能力

2023 堆参数 → 2024 堆上下文与多模态 → 2025+ 堆"思考"（推理时计算）。Scaling Law 没死，只是换了赛道。

o1 → R1 → Claude 4.5，每一次范式跃迁背后都是训练目标与测试时计算的协同进化。

主线 2 · 开源 vs 闭源

2023.07 Llama 2 开源 → 2024.07 Llama 3.1 405B（首个开源旗舰）→ 2025.01 DeepSeek-R1 震撼全球。

中美 AI 差距从"2 年"被 R1 拉回到 6–12 个月，中文开源生态 Qwen3 / GLM-4.5 已在多个基准领跑。

主线 3 · Agent 进化

2023.11 Assistant API（雏形）→ 2024.10 Computer Use（AI 第一次动手）→ 2025.05 MCP 协议标准化。

2026 年真正的护城河不是模型大小，而是 Agent SDK、Subagent 协作、工具调用生态。
