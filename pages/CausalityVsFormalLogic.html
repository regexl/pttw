因果假说 vs 形式逻辑：考场避坑指南

一、核心根源：混淆的本质

混淆的本质 = 分不清题干给的是【固定真假规则】还是【观测相关性 + 人为脑补的因果故事】

很多同学在考场上容易将“如果...那么...”的逻辑规则与“A导致B”的因果推论混为一谈。本手册旨在通过符号隔离和流程化操作，彻底根除这一混淆。

二、先定义两套完全独立的体系

原则：书写严格分开，从符号就隔离。

体系 1：形式逻辑 | 蕴含命题
  • 符号强制写： B → C
  • 题干素材： 规则、定义、制度、假设条件
  • 典型引导词： 如果… 那么；只要… 就；所有… 都；若… 则
  • 命题性质： 给定为真的静态规则，不讨论时间先后、谁造成谁
  • 逻辑规则： B → C ⇔ ¬C → ¬B (天然逆否等价)
  • 用途： 推导必然真假；肯后否前无法推出确定结论
  • 一句话： 这句话本身就是已知成立的前提，不需要我们去证明它对不对。
体系 2：论证逻辑 | 因果假说
  • 符号强制写： B ⇒ C
  • 题干素材： 野外调查、实验、统计、对比观察
  • 典型引导词： 研究发现、对比可见，因此 XX 导致 / 使得 / 降低 / 缓解 XX
  • 命题性质： 仅仅观测两件事共存（相关性）；X ⇒ Y 是作者主观猜想的因果，是待证明的结论，不是既定事实
  • 逻辑规则： B ⇒ C 不能 自动等价于 ¬C ⇒ ¬B
  • 用途： 寻找漏洞（倒置、他因）、搭桥、取反验证必要前提
  • 一句话： 因果箭头描述时间先后 + 作用关系，不是真假绑定。

三、做题固定 4 步判定流程

拿到题干立刻执行：

  1. Step 1：识别题干原材料是什么
    1）原材料是不是一条人为规定的条件语句？
    ✅ 是 → 形式逻辑，使用 →，允许逆否运算
    2）原材料是不是先摆一组观察 / 实验数据，最后得出 “A 造成 B” 的结论？
    ✅ 是 → 因果论证，使用 ⇒，禁止逆否等价运算
  2. Step 2：区分这句话是【论据】还是【结论】
    如果 B → C 放在论据部分，作为已知规则 → 可以逆否
    如果 B ⇒ C 放在结尾，是作者推出来的结论 → 这是因果假说，不能默认逆否成立
    致命易错点： 观测到「¬B 和 ¬C 同时发生」只是事实素材，本身不自带任何箭头！箭头是人自己加上去的猜想。
  3. Step 3：两套箭头严格隔离书写
    硬性书写习惯（防止大脑混淆）：
    形式逻辑：B → C
    因果猜想：B ⇒ C
    永远不要混用箭头！看到不同符号，大脑自动切换两套规则。
  4. Step 4：分别翻译二者的文字含义
    B → C：如果 B 为真，则 C 一定为真（无时间）
    B ⇒ C：B 事件先发生，之后导致 C 事件发生（有时间顺序）

四、直观对比：同一文字素材的两种解读

素材描述： 花青素高的植株，不容易被绢蝶捕食

情况 A：作为形式逻辑规则

题干原文： 只要花青素含量高 (B)，紫堇就不会被捕食 (C)

书写： B → C

逆否有效： ¬C → ¬B

含义： 这是一条既定不变的判定规则，不用纠结先后。

情况 B：作为因果论证（真题真实情况）

题干原文： 观察发现花青素高的植株更少被捕食，因此花青素高使得植株抵御绢蝶

书写： B ⇒ C

B ⇒ C： 先生成高花青素 → 之后防虫（作者假说）

¬C ⇒ ¬B： 先被捕食受伤 → 之后花青素下降（对立倒置假说）

关键点： 二者不是等价，是互相竞争、互斥的两套故事。文字句子长得一模一样，放在不同题干结构里，逻辑身份完全不同。

五、实操避坑 5 条铁律

  • 只要题干出现「调查、实验、野外发现」，结尾出现「因此导致 / 有助于」，一律禁用逆否等价思维。
  • 因果题里面，¬C ⇒ ¬B 不是天然推论，它是削弱项（因果倒置）。
  • 形式逻辑题不存在 “因果倒置” 这个考点；因果论证题不存在 “逆否必然成立”。
  • 看到两件事物相关性共存 ≠ 自动生成任何因果箭头；箭头永远是作者的主观假设。
  • 不要凭语感判断句子是否等价；先判断题型结构，再选择逻辑规则。

避坑自检问句（做完一道论证题问自己两句）

① X ⇒ Y 是题干给定的铁律吗？还是作者猜出来的？

② 如果时间顺序反过来写成 Y ⇒ X，会不会是完全相反的现实故事？

判断标准： 如果回答 “反过来故事完全不一样” → 属于因果假说，不能等价。

六、深度辨析：为什么 B⇒C 不等价于 ¬B⇒¬C？

重要结论： B ⇒ C 和 ¬B ⇒ ¬C，本身在逻辑上【根本不是等价关系】！

1. 形式逻辑回顾

B → C 唯一等价式：¬C → ¬B（逆否命题）。

¬B → ¬C 是否前，在形式逻辑里：否前推不出任何必然结论，和原式不等价！

例子：B=是狗，C=是动物。是狗→是动物（真）；不是狗→不是动物（假）。

2. 回到因果箭头 ⇒ 的真实含义

B ⇒ C = B 这个因素，能够带来 C 这个保护效果（正向作用）。

我们直觉上会补一句：花青素低 (¬B) → 更容易被咬 (¬C)。

重点： 这不是逻辑推导出来的必然结论，是我们人为假设了「单一、双向的防御机制」！它只是同一个科学假说附带的配套猜想，不是天然自带的逻辑等价物。

3. 反例证明二者可以拆开

假设：只要花青素达到高浓度阈值 B，植物获得防虫能力 C；但是花青素只要低于阈值，不管是中等含量还是极低含量，防虫效果全部失效。

  • B ⇒ C（高花青素 → 防虫 ✔成立）
  • 花青素中等（¬B）→ 依然不防虫（¬C）
  • 花青素极低（¬B）→ 不防虫（¬C）

或者：花青素只是 “锦上添花” 的辅助防御。植物就算花青素很低（¬B），还可以靠挥发气味来防虫（依然 C）。此时 B ⇒ C 成立，但 ¬B ⇒ ¬C 不成立。

4. 整理四个因果式子准确的定位

表达式 性质
B ⇒ C 作者核心因果猜想
¬B ⇒ ¬C 作者额外默认的补充预设（可被推翻，非等价）
¬C ⇒ ¬B 推翻作者的竞争假说（因果倒置，削弱项）

七、深度辨析：C⇒B 是否为必要前提？

直接给结论： C ⇒ B（不被咬 → 花青素变高）不能作为本题结论成立的必要前提。

1. 翻译 C⇒B 完整故事

C = 不被捕食（安全无虫害），B = 花青素高。

含义： 植株本身先安全、没有绢蝶侵扰（C），这个安全环境刺激植物合成更多花青素（B）。

2. 执行前提假设唯一判定工具：取反验证

规则： 选项取反之后，题干结论必须彻底无法成立。

对 C⇒B 取反： 安全无虫害，并不会催生更高的花青素。（即：就算一直不被咬，植物也不会因此合成更多花青素。）

检验： 作者的逻辑是：基因主动促进花青素，花青素带来防虫效果。即使「安全不会催生花青素」这件事是真的，基因依然可以自己拉高花青素，继续实现防虫。

👉 取反之后，结论完全可以存活。因此：C⇒B 不是必要前提。

3. 对比真正的致命倒置：¬C⇒¬B

取反 ¬C⇒¬B： 捕食不会降低花青素（正好就是选项 B）。

如果不取反（即 ¬C⇒¬B 成立）：花青素低不是防御失败的原因，而是被咬受伤带来的副作用。整套 “基因靠花青素防虫” 的因果直接作废。

👉 取反摧毁结论 → 它才是必要前提要排除的风险。

4. 因果命题如何取反（非常重要）

句子： X 导致 Y

它的否定（取反）是： X 并不会导致 Y

注意： 不是 X ⇒ ¬Y（X 导致 Y 不发生）❌

注意： 不是 ¬X ⇒ B（没有安全反而花青素高）❌

取反只是剥夺 “X 对 Y 的因果作用力”，不要求 X 反向制造相反结果。

八、一张极简对照记忆卡片

表格项目 形式逻辑 B → C 因果假说 B ⇒ C
原始材料 规则 / 定义 / 条件句 观测统计，两件事同时出现
时间先后 不关心先后 核心就是谁先发生
¬C … ¬B 的角色 等价命题，必然成立 对立竞争的倒置假说（削弱）
考点 逆否、递推、摩根 因果倒置、他因、搭桥、取反验证
能否等价变换 ✅ 允许 ❌ 禁止

规则用短箭头，可以逆否算真假；

因果用长双箭头，只比先后不比等价。

共存不等于因果，猜想不等于公理。

九、配套训练方法（彻底根除混淆）

每次做完一道论证逻辑题：

  1. 把作者因果写成 X ⇒ Y
  2. 手动写出倒置版本 Y ⇒ X
  3. 用大白话分别翻译两个故事，对比是不是两套完全不一样的现实过程
  4. 只要两个故事不一样，就证明它不是形式逻辑的等价命题。
