一、题型识别：什么才是组合排列

三个判定特征（同时满足即为组合排列）
  1. 存在两组及以上对象（如：人与职务 / 人与爱好 / 人与地点 / 物品与容器 / 编号与对象）；
  2. 对象之间存在对应关系或比较关系（谁是谁、谁在谁前面、谁比谁大）；
  3. 要求推出"谁是谁"或"谁在哪"。

原讲义比喻：组合排列类似"柯南游戏"——给出一批人和人与人之间的信息，要求推出每个人在哪里。

题目难度趋势

组合排列可以考得很难，完全不知道从何下手时容易靠运气；但近年的组合排列题越来越简单，特别难的题目很少。所以在规定时间内做出来，关键不是"更聪明"，而是按题型找到破题点。

考查趋势

逻辑题型很多，各省国考省考比较喜欢以论证为主考查，因此组合排列常与其他推理题结合出现——最典型的就是与翻译推理结合，这正是本讲的第四个结构。

二、四大经典结构总览（破题点速查）

STRUCTURE 01
比大小
找最值，做排除
题干出现"最贵/最便宜/最大/最小"等最值表述时，改用反向思维，找"谁一定不是最值"来排除选项。
STRUCTURE 02
排序题
列表格
表格只写序号；确定信息先填；问"一定正确/由此推出"走推理，问"可能/不可能"走代入。
STRUCTURE 03
一对一错
最小信息假设
每人说两句话且一对一错时，找到只出现 1 次的那个信息，假设它为真再顺推。
STRUCTURE 04
翻译推理结合
找肯前 / 否后
题干出现"如果…那么…"，这句就是破题点，找肯前推肯后或否后推否前的信息。
四个结构的适用顺序建议

拿到组合排列题，先用第 1 节的三个特征确认题型归属，再按上表选破题点。若一个题同时具备多个结构特征（如既有最值又有排序），优先用"信息量更大、更容易落地"的那个——通常是排序题列表格或翻译推理破题。

三、结构一：比大小 —— 找最值，做排除

破题点：找最值，做排除

典型场景：成绩、收入、身高、年龄、前后顺序等一切可比较的量。

核心手法（反向思维）：题干一旦出现"最贵/最便宜/最大/最小"，不要顺着"谁是最值"去想，而要问"谁一定不是最值"，然后拿这个结论去排除选项。

3.1 三条推导规则

已知条件能推出为什么
"X 最贵" + "A 比 B 贵"A 不是最便宜的A 既然比 B 贵，就不可能是最便宜的那个
"X 最贵" + "B 比 A 贵"A 不是最贵的虽然不知道 B 是不是最贵，但 A 一定不是
"某人是最大的" + "丙比某点小"丙不是最大的比较双方都可以推出"不是最值"的一方

推论链的价值：当"甲、乙、丙都不是最大的"三者凑齐时，最大者被唯一确定，随之其他人的归属也锁定。这就是排除法的完整闭环。

3.2 使用要点

  • 只在有最值表述时才用这套。没有最值的比大小题，仍按普通推理走。
  • 比较关系写成"A > B"这种形式对做题帮助不大，必须转成"谁一定不是最值"的结论。
  • 近年比大小题几乎都会给最值表述，用排除法做非常快——这是性价比最高的一类结构。
  • 选项中出现"某人是最值/某人不是最值"的表述，直接对号入座排除，不要重新推全排列。

四、结构二：排序题 —— 列表格

破题点：列表格

题型两种形态：① 从左到右 / 从上到下的线性排序（有 1 号位，考查多）；② 圆桌排序（没有 1 号位，考查较少）。

工具：表格。只写序号 1、2、3、4……，把信息标注上去，不要写人名，避免抄写错误。

4.1 提问方式决定解法（关键分叉）

提问方式解法原因
一定正确 / 由此可以推出列表格 + 从确定信息出发推理 代入题干只能推出"可能对""符合题干意思"，不等于一定对——同一位置可能是甲也可能是乙，代入两个选项都"符合"，所以不能用来证明"一定正确"。
可能 / 不可能代入法（确定信息可先填，但大概率还要代入） "可能对"意味着不确定；四个选项里三个可能、一个不可能，代入排除比推理更快，也避免推出一堆用不上的信息。

实操：先列出表格，把确定信息（如"某人是第几位"）填进去，再按顺序读条件。

4.2 间隔信息：排序题的隐形王牌

间隔信息的两条性质
  • 双向锁定："甲和乙中间隔了 2 个人"——知道甲的位置，乙的位置立刻确定；知道乙的位置，甲的位置也确定。
  • 占地大：间隔 2 人意味着连头带尾共占 4 个位置，间隔人数越多的条件优先放入表格，越容易先锁定结构。
【间隔记法】
甲和乙中间隔了 2 个人  →  甲××乙  或  乙××甲
（"×" = 中间隔着的人；两种写法都成立，除非题干额外说明"甲在前面"，此时才唯一）

用法：遇到"谁和谁间隔了 N 个人"，这往往就是破题的关键点；因为它同时给出确定信息（占几个位置）和相对顺序，信息密度最高，应优先处理。

4.3 填表顺序：先确定，再顺藤摸瓜

  1. 列表格，只写序号。
  2. 先填确定信息：谁在第几位、谁在最左/最右、谁不在某位。
  3. 顺藤摸瓜：填进去的信息涉及了谁，就回到题干找提到这个人的条件；没有提到就看下一条。
  4. 间隔条件优先：剩余条件中，间隔人数多的先放（占地大、约束强）。
  5. 需要时再代入：问"可能/不可能"且表格推不出结论时，逐项代入验证。

五、结构三：一对一错 —— 最小信息假设

破题点：最小信息假设

适用模型：题干里每个人都说了两句话，并且已知这些猜测一对一错（每人一组话里恰好一对一错，但不知道哪句对、哪句错）。

5.1 方法本体

三步动作：

  1. 找最小信息——把所有"人名 / 位置 / 事物"的提及次数统计一遍，找出只出现 1 次的那个信息。
  2. 假设它为真——"出现次数最少的信息，正确"。
  3. 顺着它推——用它触发其他条件，把整组关系推完，再看设问。

为什么能假设为真：因为"一对一错"是硬约束，若最小信息是错的，则同一组里的另一句话必然是对的；而按最小信息为真往下推，结果目前所有此类题目都能自洽（原讲义明确：这种"最小信息为假"的情形目前尚未遇到）。

边界情况

如果没有找到只出现 1 次的信息，最小信息假设法失效，只能用代入法（因为"只对了一半"意味着不知道哪句对，必须逐项代入试）。

5.2 统计视角：数人还是数物

同一个题，既可以数"人名"出现次数，也可以数"事物/位置"出现次数，哪边更容易找到只出现 1 次的就用哪边。

统计对象典型载体备注
人名几个人物在几句话里被提到如"丙"只出现一次
事物 / 位置编号、职位、爱好、地点如某个编号只出现一次、某个身份只出现一次
组合体"某人是某身份"这一整句整句作为一条信息参与计数

注：统计时必须逐句认真数，漏数或多数都会导致最小信息判断错误——原讲义把"数错最小信息"列为该方法的主要失败原因。

5.3 与真假推理的区别

组合排列里的"一对一错"：同一人的两句话中一对一错，不知道哪句对，所以用最小信息假设。

标准真假推理题：题干几句话中，一整句话对，或者一整句话错（整句判定，不拆），走另一套真假推理规则（如矛盾关系、反对关系）。

六、结构四：与翻译推理结合 —— 肯前 / 否后

破题点：题干出现"如果…那么…"，这句就是破题点

组合排列题涉及推理，逻辑性较强；很多地方的考试喜欢以论证为主考查，所以组合排列常与翻译推理结合。识别出翻译句之后，只做两件事：找肯前、找否后。

6.1 唯一可用的两条推理方向

基础公式：A → B　等价于　¬B → ¬A（逆否等价）

要找的信息推理方向能推出什么
A（前件为真）肯前必肯后必然推出 B
¬B（后件为假）否后必否前必然推出 ¬A
¬A（前件为假）否前无必然结论，不能用来破题
B（后件为真）肯后无必然结论，不能用来破题

找信息时的两条纪律：① 要找 A，不要找 ¬A；② 要找 ¬B，不要找 B。反过来说：看到"某人不是 A"，对否前没用；看到"某人就是 B"，是肯后，也没用。真正有用的信号只有"某人就是 A"和"某人不是 B"。

6.2 代入法与翻译的配合

  • 设问出现"可能 / 不可能" → 用代入法；此时代入方向要选对：如果 A 出现在箭头前，就优先代入"A 成立"的选项（肯前推肯后）；如果设问方向是"不是 B"，就优先代入"¬B"的选项（否后推否前）。
  • 设问出现"可以推出 / 一定正确" → 走列表格推理，从确定信息出发。
  • 信息量大时，列表格 + 代入同时用：先列表格，再优先代入与翻译句相关的那两个选项，通常两三个选项就能排除完。

6.3 分组类题目的数量前提

读题时必须先算清名额

分组题里，名额结构就是破题点的一部分。题干常见表述"每个小区安排 1 至 2 人"，5 人分 3 组且每组 1~2 人 → 立刻得出唯一结构 1、2、2；再叠加"某组人最少"之类的条件，就能把人数锁死。

数量结构一旦确定，翻译句的否后往往就出来了（例如"某组只有某人"与"该组实际有 2 人"矛盾 → 否后成立 → 反推否前）。

七、通用解题流程与「顺藤摸瓜」

组合排列题通用四步
  1. 定题型——用"两组对象 + 对应关系 + 推出谁是谁"三个特征确认属于组合排列，再判断落在四大结构的哪一个（比大小 / 排序 / 一对一错 / 翻译结合）。
  2. 找破题点——按结构取破题点：最值（比大小）、确定信息 + 间隔（排序）、只出现一次的信息（一对一错）、"如果…那么…"（翻译结合）。
  3. 顺藤摸瓜——得到一个结论后，立刻回头找题干中提到这个结论（这个人/这个位置/这个事物）的条件，顺着继续推。
  4. 结合设问——问谁就往谁身上靠。已得的结论如果与设问对象无关，它就只是"跳板"，要主动向设问对象靠拢。
「顺藤摸瓜」是什么意思

这是组合排列题最核心的推进方式：推出一条结论后，不要停下来从头重读，而是拿着这条结论回到题干里找"提到它"的那一条条件，用这条条件继续推下一条，形成链条。

为什么要"结合设问"：题干里关于其他人的信息可能很多，但设问只问一个人。前面推出来的结论如果问的不是它，就当"跳板"用完即弃，把注意力转到设问对象上。

原讲义强调：条件（2）（4）先看，是因为它们涉及最值与比大小；推出关于某人的结论后去看提到他的条件，都是这一思路的应用。

八、细节规则与文字陷阱清单

八条必须知道的规则
  1. 题干每一句话都不是废话。题干里突然冒出一个新概念（学历、批评/表扬、性别、类别），就要下意识回到题干找提到该概念的条件。原讲义举例：出现"批评和表扬"，就去找哪句提到批评和表扬；出现"硕士"，就去找哪句提到硕士。
  2. 同一句话里的不同主体，默认是不同的人。"A 和 B 住在同一幢公寓楼""A、B、C 经常一起打球""A、B 和 C 结伴旅行"——一般不说某人和自己住一起，所以这些表述意味着是几个不同的人。这是组合排列里最常用的"主体拆分"工具。
  3. 比较关系能推出"谁一定不是最值"。见结构一，但反过来不成立：知道"某人不是最小的"，推不出他具体是多少。
  4. 间隔信息双向锁定、占地大，且默认两种顺序都成立，除非题干说明谁在前。
  5. 排序题有两种形态：线性排序（有 1 号位，常见）与圆桌排序（无 1 号位，考查较少）。
  6. 用"＞"排列顺序号的方法可行但慢，近年这类题目很少；原讲义明确不推荐作为主力方法，列表格才是标准动作。
  7. 最小信息假设的前提是"一对一错"；若题干是"一整句对或一整句错"，那属于真假推理，走另一套规则。
  8. 数量类限制要单独看："每人均需至少完成其中一项工作，一项工作只能由一人完成"——前者保证不漏项、后者保证不重复，两者共同决定"主体互斥"的用法。
时间观（考场节奏）
  • 不是所有题都能 1 分钟做完。像"排序 + 间隔 + 翻译"这种组合题，考场上1.5~2 分钟做出来都是划算的（题库正确率通常 50%~60%，与数量题用时相当）。
  • 简单题要更快：类比推理可能半分钟一道，省下的时间补给难题。
  • 课上不要只听"乐子"——原讲义特别强调：关键不是这道题答案选什么，而是"下次遇到这样的题该怎么破题"。
  • 事业单位联考 D 类考职测，判断推理一般 30~35 题，有可能考查组合排列题，鄂州市事业单位同样需要准备这一题型。

开考前 30 秒默背

1. 定题型（两组对象 + 对应关系 + 推出谁是谁）

· 题干每句话都不是废话：冒出新概念就去找对应条件
· 同一句里不同主体默认是不同的人（拆分用）
· 表格只写序号，别抄人名
最后一句

组合排列的"快"不来自聪明，而来自套路识别：看到最值就做排除，看到排序就列表格，看到一对一错就找最小信息，看到"如果…那么…"就找肯前否后。四套动作任选其一切入，五道小问的时间就出来了。
