逻辑学核心概念手册

系统梳理直言命题、复合命题、谓词逻辑、条件推理、因果关系与归纳演绎等核心概念，厘清易混淆术语之间的层级与区别。

一、AEIO 与文氏图

核心区别

AEIO 是 4 种直言命题（语言形式，是逻辑陈述本身）；文氏图是图形工具，用来可视化表达 AEIO、检验三段论推理有效性。二者不是并列的两套理论，而是命题和命题的图形表示的关系。

AEIO：四种直言命题

直言命题陈述两个类（S 主项、P 谓项）之间的包含/排斥关系：

A
全称肯定
所有 S 是 P
E
全称否定
所有 S 不是 P
I
特称肯定
有的 S 是 P
O
特称否定
有的 S 不是 P

AEIO 负责给出断言，可以用对当方阵研究它们之间的真假关系（矛盾、反对、差等）。

文氏图：可视化工具

用相交圆圈代表集合：阴影表示该区域为空集；X表示该区域至少有一个元素。

A：所有 S 是 P
S 独有区涂黑
E：没有 S 是 P
交集涂黑
I：有的 S 是 P
交集放 X
O：有的 S 不是 P
S 独有区放 X

为什么文氏图 ≠ AEIO

AEIO 是命题（判断），本身有真假；文氏图只是图形符号，图形本身没有真假，只是用来翻译、表示 AEIO 的工具。工具 ≠ 被描述的内容。

  • 同一个 A 命题「所有 S 是 P」，可以用文氏图画，也可以用欧拉图画——命题不变，表示它的图形可以换。
  • 文氏图只是圆圈+阴影+X，不懂符号约定就读不出意义。
项目AEIO文氏图
本质4 种标准直言命题图示方法、推理工具
载体文字、符号语句相交圆圈、阴影、X 标记
作用表达类与类之间的断定，研究对当关系把 AEIO 可视化，检验三段论有效性
真假本身有真假图形没有真假，只展示命题含义

二、四大命题与矛盾命题

命题是可以判断真假的陈述句，分为简单命题（直言）和复合命题（联言、选言、假言）。

1. 直言命题（简单命题，AEIO）

描述某个/某类事物具有或不具有某种性质，只有一个断定。

直言矛盾（反命题）口诀

所有 ↔ 有的，是 ↔ 不是

  • 所有 S 是 P ↔ 有的 S 不是 P
  • 所有 S 不是 P ↔ 有的 S 是 P

2. 联言命题（A 且 B）

A 和 B 同时成立，形式 A ∧ B。

真假规则：全真才真，一假即假。

矛盾命题：非 A 或 非 B（至少一个不成立）。

3. 选言命题

相容选言：A 或 B

A、B 至少一个成立（可同时成立），A ∨ B。

真假：一真即真，全假才假。

矛盾：非 A 且 非 B。

不相容选言：要么 A 要么 B

A、B 有且只有一个成立。

真假：一真一假才真；同真同假都假。

矛盾：(A 且 B) 或 (非 A 且 非 B)。

4. 假言命题（条件命题）

描述条件关系：如果…那么；只有…才。

  • 充分条件：如果 A，那么 B → A → B（有 A 一定有 B）
  • 必要条件：只有 A，才 B → B → A（没 A 一定没 B）
翻译口诀 & 真假规则

如果就，前推后；只有才，后推前。

真假规则：只有 A 真 B 假时，A→B 才为假；其余情况全部为真。

矛盾命题：A 且 非 B（不是 A→非 B！）

矛盾命题总表

命题类型原命题矛盾命题（反命题）
直言 A所有 S 是 P有的 S 不是 P
直言 E所有 S 不是 P有的 S 是 P
直言 I有的 S 是 P所有 S 不是 P
直言 O有的 S 不是 P所有 S 是 P
联言A 且 B非 A 或 非 B
相容选言A 或 B非 A 且 非 B
不相容选言要么 A 要么 B(A 且 B) 或 (非 A 且 非 B)
假言A → BA 且 非 B
高频易错点
  • "有的"在逻辑里 = 至少一个，≠ 部分，不是"有的是就有的不是"。
  • 假言命题矛盾是联言，不是另一个假言。
  • 矛盾命题：必有一真一假，不能同真同假。

三、Predicate 谓词

一句话定义

谓词用来描述个体对象的属性或对象之间的关系，带空位，填上个体才会变成有真假的命题。

基础结构

  • 个体：对象（x、a、张三、苏格拉底）
  • 谓词 P( )："…是 P"，括号是空位，用来放个体
一元谓词（描述属性）

M(x)：x 是人
D(x)：x 会死

AEIO 用的就是一元谓词

二元谓词（描述关系）

L(x,y)：x 喜欢 y
G(x,y)：x 大于 y

传统 AEIO/三段论处理不了关系！

P(x) 本身不是命题！因为 x 是空变量，没有固定真假；填入具体个体 M(苏格拉底) 才变成命题。

把 AEIO 翻译成谓词公式

∀ = 全称量词「所有」；∃ = 存在量词「有的」

A：所有 S 是 P → ∀x ( S(x) → P(x) ) E：所有 S 不是 P → ∀x ( S(x) → ¬P(x) ) I：有的 S 是 P → ∃x ( S(x) ∧ P(x) ) O：有的 S 不是 P → ∃x ( S(x) ∧ ¬P(x) )
核心考点

全称 A/E 用 →（假言）；特称 I/O 用 ∧（联言）。

传统 AEIO vs 现代谓词逻辑

维度传统直言命题（AEIO）Predicate 谓词逻辑
拆解方式量项 + 主项 S + 联项 + 谓项 P个体 + 属性/关系 + 量词
表达能力只研究两个类之间的包含排斥既能表达 AEIO，还能表达关系命题、嵌套量词
地位词项逻辑（亚里士多德）现代一阶逻辑，AEIO 是其子集

量词的矛盾（德摩根量词律）

¬∀x F(x) ⟺ ∃x ¬F(x) ¬∃x F(x) ⟺ ∀x ¬F(x)

即：∀ 的矛盾是 ∃，再否定后面整个式子。

四、条件命题与因推果 / 果推因

核心区分

条件命题（假言）是逻辑蕴含（演绎推理）；因推果、果推因是现实因果推理。逻辑推出 ≠ 现实因果。

条件命题的两类

充分条件：A → B

如果 A，那么 B。有 A 就一定有 B（因推果）。

例：下雨 → 地面湿。

必要条件：B → A

只有 A，才 B。有 B，则一定有 A（果推因）。

例：考试 → 一定报名了。

因推果与果推因

因推果（由因预测果）

已知原因 A 成立，推测结果 B 会发生。

例：下雨了 → 地面会湿。

对应充分条件 A→B，演绎成立。

果推因（溯因推理）

已知结果 B 已发生，反推原因 A 存在。

例：地面湿了 → 下雨了？

或然推理，结论只是猜想，不是 B→A！

最大坑点

地面湿了，不一定是下雨，可能是洒水车。普通溯因（看到结果猜原因）≠ 必要条件的 B→A。

必要条件里的"果推因"是演绎有效（结果 B 发生 → 必备前提 A 一定存在）；普通溯因只是或然猜想。

对比项条件命题（A→B）现实因推果 / 果推因
推理类型演绎推理，必然真因果推理：因推果（预测）、果推因（溯因，或然）
时间无时间先后要求，只看真假一定有时间先后：因在前，果在后
含义A 真则 B 真，不管谁造成谁A 造成 B，是因果作用、产生关系
逆命题A→B 不能推出 B→A看到结果 B 猜测 A 是溯因习惯，逻辑不保证

五、真值关系 vs 因果关系

真值关系（逻辑蕴含）

只看两个语句的真假组合，不管现实世界谁引起谁、时间先后。属于语言/命题层面。

A→B 的规则只看 4 种真假组合：

  • A 真 B 真 → 真
  • A 真 B 假 → 假（唯一假情况）
  • A 假 B 真 → 真
  • A 假 B 假 → 真
因果关系

现实世界里一件事产生、导致另一件事，有时间先后、作用机制。属于事实层面。

A 是原因，B 是结果：A 发生，造成 B 发生；因一定在时间上先于果。

例：下雨 → 地面湿。

实质蕴含悖论

例："如果 2+2=5，那么月亮是奶酪做的。" 在逻辑上这个蕴含式为真（前件假，整个式子自动为真），但现实完全没有任何因果。

这就是为什么逻辑里的"如果…那么…"不是日常语言里的因果。

一句话：真值是真假配对规则（静态、无时间、不管实际作用）；因果是事件产生作用（动态、时间先后、现实作用）。

六、概念辨析：条件 / 蕴含 / 演绎 / 命题

结论先行

不是同义词，不能互换。它们是不同维度的概念。

命题 （大类：能判定真假的陈述句） └─ 条件命题（假言命题） （其中一类复合命题） 　　└─ 内部使用 蕴含 → （联结词，表达真值关系） 　　　　└─ 用命题做推导的过程 = 演绎推理 （推理活动）
术语维度含义
命题大类名称能判定真假的陈述句
条件命题命题种类"如果…那么…"这种复合命题，是一个陈述
蕴含（→）联结词条件命题内部表达真值关系的逻辑符号
演绎推理类型从前提必然推出结论的整套推理活动
类比：句子（命题）里的"如果…那么…"（蕴含连词）；拿这个句子做推导的思考过程叫演绎。四个词在不同层级。

七、命题别名总表

简单命题

内部不含逻辑联结词，不能拆成更小命题。别名：原子命题。包含直言命题（性质命题）和关系命题。

复合命题

由简单命题 + 联结词拼接而成。

传统 AEIO 里的"谓项 P"（predicate term，名词类如"哺乳动物"）≠ 现代谓词逻辑的"谓词"（predicate，P(x) 命题函数）。

八、归纳推理 vs 演绎推理

一句话总纲

演绎：前提真 → 结论必然真（必然性推理）
归纳：前提真 → 结论只是大概率真（或然性推理）

演绎推理（Deductive）

从一般性大前提，推个别结论；保真推理。

核心特征：前提蕴含结论。只要前提全部为真、推理形式有效，结论一定为真。

本质：结论信息已包含在前提里，没有新增知识。

典型工具：三段论、AEIO、假言/联言/选言命题、谓词逻辑。

归纳推理（Inductive）

从多个个别案例，推出一般性结论；不保真，或然推理。

核心特征：前提都是真，结论仍可能假。结论信息超出前提范围。

分类：完全归纳（穷尽全部样本，必然）；不完全归纳（部分样本推广，或然，考试主流）。

典型方法：样本统计、枚举、穆勒五法。

溯因推理（Abduction）

很多教材单独列出，不属于演绎也不属于归纳：

已知结果 + 背景知识，猜测最合理的原因（或然猜想）。例：地面湿了 → 猜想下雨了。结论只是最佳假说，不是必然成立。
项目演绎推理归纳推理（不完全）
推理方向一般 → 个别个别 → 一般
推理性质必然性推理（保真）或然性推理（不保真）
信息增量结论不超出前提结论超出前提，得到新概括
前提真时形式有效则结论一定真前提全真，结论仍可能假
削弱方式不能削弱形式有效性，只能攻击前提真假可加强（扩大样本）、削弱（举反例）
高频易错
  • 演绎不一定都是"一般到个别"，现代逻辑核心判定标准是是否保真。
  • 假言命题做推理：下雨→地湿；下雨了所以地湿（演绎，必然）；地湿了所以下雨了（溯因，猜想，或然）。
  • 演绎只管结构，不管现实因果；归纳/溯因才大量用来研究现实因果。

三者极简区分

演绎
前提全对，结论一定对（必然）
归纳
看到很多个例，总结普遍规律（大概率，可被反例推翻）
溯因
看到结果，倒猜原因（找最合理解释，猜想）
配套关系
命题是演绎素材；归纳靠观察样本；真值关系属演绎，因果属归纳/溯因
