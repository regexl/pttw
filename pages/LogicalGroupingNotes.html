考点 01

集合唯一性语义 vs 个体事件

触发规则 当句式为 "只有 + 对象 + 地点" 整体作为条件，后面接 "否则"，且题型是分组分配题时，触发集合唯一性语义。

一、集合唯一性语义（集合层面）

条件约束的是整组/整套分配方案，而不是单个个体。"否则"否定的是整个分组结果。

  • 约束主体：分组集合（一整套分配结果）
  • "否则"否定：整套分组方案，方案直接作废
  • 唯一性含义：所有合法可行的分组集合必须统一满足这条规则，不满足的集合直接淘汰
  • 后果：只要条件破了，所有人的安排一起作废

二、个体事件（个体层面）

条件只描述某一个单独元素发生什么事，和其他元素无关。

  • 约束主体：单独某一个对象
  • "否则"否定：仅该个体自身的结果，其他人不受影响
  • 后果：这个个体不满足，只是这个个体失效，其余元素仍可正常分配
集合唯一性
只有甲在A组，否则分组不成立。
方案成立 → 甲在A
甲不在A → 整套方案×
甲不在A → 这一种分组直接排除，不看乙放哪
个体事件
只有甲在A组，否则甲不能参加。
甲能入选 → 甲在A
甲不在A → 甲×，乙丙照常
甲不在A → 甲出局，但乙丙仍可正常分组

三、对比表

对比维度集合唯一性个体事件

否则否定否定整套方案，直接无效仅否定该个体，他人不受影响

集合唯一性：不满足 → 整套方案废掉
个体事件：不满足 → 只淘汰这个人
考点 02

"只有…否则…"的判断标准

常见误区 不能用"前后分句是不是同一个个体"来判断！这只是表象，会导致误判。

真正的判断标准

看"否则"后面被否定的主体是谁：

  • 否定整套分组/方案有效 → 集合唯一性事件
  • 否定某个人的资格（甲不能入选、乙不能分配）→ 个体事件

反例验证

前后同一对象，但却是集合事件
只有甲在A组，否则本次分组不成立。
"只有"主体是甲，"否则"否定的是整套分组 → 集合唯一性
前后不同对象，但可以是个体事件
只有甲在A组，否则乙不能参加分配。
"否则"否定的是乙（个体）→ 个体事件，剩下的人还能继续排
快速口诀 看否则否定的是谁：否定整套方案 = 集合；否定某个人 = 个体。
补充说明 原触发规则（分组分配题 + "只有+对象+地点，否则……"）默认"否则"指向整套方案，直接触发集合唯一性。但如果否则后面明确写的是某个人，哪怕是分组题，也要回归个体事件。
考点 03

并列选言 vs 假言命题陷阱

高频陷阱 "如果甲去A或B，乙去C或D" —— 很多人下意识当成假言（甲→乙），但这句话没有关联词连接前后半句，它只是两个独立选言命题并列放置！

正确翻译

// 两个选言命题的联言，不是假言！ (甲A ∨ 甲B) ∧ (乙C ∨ 乙D)

含义：两个约束必须同时满足——甲只能A或B，乙只能C或D。甲不管分到A还是B，乙永远必须C或D，不存在"甲不在A/B，乙就放开"的情况。

假言 vs 并列选言 对比

类型句式特征逻辑翻译与含义
假言命题 有完整"如果…那么…"
如果甲去A或B，那么乙去C或D		 (甲A∨甲B) → (乙C∨乙D)
甲落在A/B时乙必须C/D；甲不在A/B时规则失效，乙不受约束
并列双选言 只写"如果甲A或B，乙C或D"
无"那么"，单纯并列条件		 (甲A∨甲B) ∧ (乙C∨乙D)
两个约束同时成立，甲去C直接违反第一约束，整套作废；乙永远必须C/D
有那么，才是推；
只摆两个限制并列，是且不是推。
联动考点 这种并列选言约束属于对整套分组的硬性规则，违反直接淘汰整套方案，属于集合层面约束，不是个体事件。
考点 04

硬性约束优先级原则

核心原则 硬性约束（必须是什么）比"不是什么"（否定约束）更准确，优先利用。
先抓必须是，再看不能是；正向硬约束是推理第一序。

一、正向硬性约束（必须是什么）

直接给出对象/组别确定归属或可选范围，是"必须满足"的硬规则，优先级最高。

  • 甲只能在A或B → 甲∈{A,B}（正向划定候选池）
  • 乙一定在C
  • 只有甲在A，否则分组无效（集合唯一性）
  • 甲乙必须同组

优势：直接锁定位置/候选池，可以直接填表，是推理起点。

二、反向约束（不能是什么）

只说不能放哪，可选范围依然很大，信息弱。

  • 甲不在A
  • 丙不能和丁一组
  • 乙不去B

缺点：只排除一个可能性，单独使用很难得到确定结果，大多后期筛选项。

三、三类约束优先级

第一优先级
正向硬性约束
必须是什么
直接锁定候选池，填表落地
→↓
第二优先级
反向否定约束
不能是什么
结合正向信息缩小范围
→↓
第三优先级
假言条件
如果…那么…
条件触发型，前件成立才激活
为什么假言放最后 假言只有前件成立时才生效；前件不成立，这条规则恒真（没用）。不能把假言当固定事实，它是条件触发型规则。

四、三大考点的约束性质归类

考点约束性质优先级
集合唯一性（只有…否则…分组题）正向硬性约束高，整套方案必须满足
并列选言（甲A或B，乙C或D）正向硬性约束高，固定必须同时满足
如果…那么…假言命题条件规则（非事实）低，前件成立才激活
避坑指南

高频错误汇总

1

用"前后分句是否同一个体"判断集合/个体事件

误以为前后主体相同就是个体事件，不同就是集合事件。实际上主体是否相同只是表象。

看"否则"后面否定的是谁：否定整套方案=集合，否定某个人=个体。
2

把并列选言误当成假言命题

"如果甲去A或B，乙去C或D"没有"那么"，不是(甲A∨甲B)→(乙C∨乙D)，而是两个选言的联言。

有"那么"才是推，只摆两个限制并列是且不是推。
3

上来就抓反向约束（不能是什么）反复试错

拿着"甲不在A""乙不去B"一堆否定条件穷举，效率极低且容易漏。

先提取所有正向硬性约束填表锁定候选池，再用反向约束缩小范围。
4

把假言命题当固定事实使用

看到"如果甲在A，那么乙在B"就直接写乙在B，忽略前件是否成立。

假言是条件规则，只有前件成立时才激活；前件不成立时这条规则无效。
5

集合唯一性误解为"这个位置只能放这一个人"

以为"只有甲在A"意味着A组不能放别人，实际上它是方案成立的必要条件。

集合唯一性=如果方案要成立就必须满足对象在该地点；不满足则整套方案排除。
6

个体事件中误以为条件破坏会导致整套分组作废

"只有甲在A，否则甲不能参加"——甲不在A时，误以为乙丙的分组也无效。

个体事件只淘汰该个体，其余元素仍可正常分配，整套框架还能存在。
实战流程

标准解题流程

第一步：读题标记，分类约束

通读题干，把所有条件按性质分类标记：

  • 【正向硬约束】必须是什么、只能在哪、集合唯一性、并列选言
  • 【反向约束】不能是什么、不和谁一组
  • 【假言条件】如果…那么…（最后处理）

第二步：正向硬约束先填表

把所有正向硬性约束直接写入表格，锁定每个对象的候选池：

  • "甲只能A或B" → 甲候选池={A,B}
  • "乙一定在C" → 乙=C，同时C排除其他对象
  • 集合唯一性条件 → 记录为方案必要条件

第三步：反向约束缩小范围

用反向约束在候选池中做排除，正反结合推出确定结论：

// 正反结合出确定结论 甲只能A或B + 甲不在A = 甲只能B

第四步：假言条件最后激活

当前三步推出确定信息后，检查哪些假言的前件已经成立，激活对应后件；前件不成立的假言暂时搁置。

第五步：代入选项验证

用排除法验证选项，注意：违反正向硬约束的选项直接排除，不需要完整推理。

先抓必须是，再看不能是；
正向硬约束，推理第一序；
假言放最后，触发才启用。
