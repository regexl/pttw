一、包含 ⊇ 与 包含于 ⊂ 的区别

1. 符号一眼分清

A ⊇ B：A 包含 B
A 是大集合，B 是小的，B 的全部元素都在 A 里面
A ⊆ B：A 包含于 B
A 是小集合，A 的全部元素都在 B 里面
💡 口诀：开口对着大集合 — ⊃ 开口朝左 → 左边大；⊂ 开口朝右 → 右边大

2. 举例子

设 A = {1,2,3}，B = {1,2}

  • A ⊇ B — A 包含 B（A更大）
  • B ⊆ A — B 包含于 A（B被装在A里面）

3. 严格版（真包含 / 真包含于）

  • A ⊋ B — A真包含B，B在A里，而且A还有多余元素，两者不相等
  • A ⊊ B — A真包含于B，A在B里，两者不相等
一句话总结：
X 包含 Y → X ⊇ Y，X包住Y，X大
X 包含于 Y → X ⊆ Y，X被Y包住，Y大

二、"于"字怎么理解？原理是什么？

核心本质：于 = 在……之中 / 被……容纳 — 自带被动含义

1. 词语拆开看

包含（主动）
动词：A去包住B
A 包含 B → A是容器，主动装着B
A ⊇ B
包含于（被动）
于 = 介词：被 / 在…里面
A 包含于 B → A被B包含
A ⊆ B

2. 文言文中的"于"（被动标记）

  • 受制于人 = 被人制约
  • 见笑于大方之家 = 被行家笑话
通用公式：X + 动词 + 于 + Y = X 被 Y 怎么样
套回去：A 包含 于 B = A 被 B 包含

3. 语序陷阱原理

汉语语序：主语在前。同一个关系有两种说法：

  • 主动说法：B 包含 A（B是主语，B大）
  • 被动说法：A 包含于 B（A是主语，但A小！）

动作还是"包含"，加一个于，主语和宾语直接调换主次。

💡 后面带于，前面变小；开口永远向着大那一边。

三、集合推理 — 和"包含/包含于"同源的坑

同义替换词总结（直接背）

语句逻辑关系谁大
A是B的一种 / A属于BA ⊊ BB大
B包括A / B包含AA ⊊ BB大
A包含于B / A被B包含A ⊊ BB大
B容纳A = A被B容纳A ⊊ BB大
⚠️ 经典坑：读句子只看先后，忽略动词。
"B被A包含" = B ⊆ A，很多人直接写成 A ⊆ B，错！

四、逻辑判断·翻译推理 — 介词大坑

1. 取决于 / 依赖于 / 有赖于

A取决于B → A ⇒ B（A的成立，必须要有B）
例：成功取决于努力 → 成功→努力
努力→成功 ← 很多人反过来，错！

2. 以A为前提 / 以A为基础

B以A为基础 → B ⇒ A
核心规律：X以Y为前提 ⇒ X→Y

3. 必要条件大坑：只有…才；除非…否则不

句式翻译方向
如果A，那么BA → B前推后
只有A，才BB → A后推前 ⚠️
除非A，否则不BB → A后推前 ⚠️
⚠️ 超级高频坑：看到"只有"直接前推后，必错！

4. 来源于

A来源于B：A的前提是B，不要随便逆推（B不一定推出A）。

五、资料分析 — 文字语序坑（每年必考）

1. A是B的几倍 vs A比B多几倍

表述公式注意
A是B的n倍A ÷ B = n直接除
A比B多n倍A ÷ B − 1 = n要减1 ⚠️
A高出B3倍A ÷ B = 4"高出"=多几倍，实际是4倍

2. 占比主语陷阱（和包含于逻辑一模一样！）

表述分子分母
A占B的比重AB
B中A的占比AB
B占A的比重BA ⚠️ 语序一变直接颠倒

3. 降幅扩大/收窄

去年降幅3%，今年降幅扩大到5% → 去年：-3%，今年：-5%
去年降幅3%，今年降幅收窄到1% → 去年：-3%，今年：-1%

4. 平均数：A平均每个B

💡 口诀：每字后面做分母！
人均GDP = GDP ÷ 人数
单位面积产量 = 产量 ÷ 面积

六、类比推理 — 最容易搞反先后、主次

关系类型示例（前→后）坑点
原材料对应木材：家具选项反过来：家具：木材，直接掉坑
功能关系手机：通讯（主要）手机：拍照（次要），注意主次
因果关系下雨：地湿（原因→结果）反过来：地湿：下雨，错
方式目的植树：绿化（方式→目的）注意方向

和"于"相关的类比词

  • 作用于：A作用于B（A施加给B）
  • 适用于：A适用于B（A的适用对象是B）

七、言语理解 — 介词造成主客体颠倒（细节判断题）

⚠️ 经典错误选项：偷换主客体
原文：A对B产生影响
错误选项：B对A产生影响

关键词识别

看到以下词，立刻警觉主客体是否被调换：

  • 对、对于：A对B ≠ B对A
  • 于、被：A被B改变 ≠ A改变B
  • 为…所：A为B所改变 = A被B改变

和"包含于"本质完全一致："被""于"直接反转两者关系。

八、统一底层原理 + 考场口诀

所有坑通用的底层原理

没有介词（主动）
A作用B → A主动，A是施加方
带上「于 / 被」
A被B作用 / A作用于B → B才是施加动作的一方

🎯 考场默念四口诀

① 带于带被，前后反转（集合、逻辑、言语通用）
② 只有才，后推前；如果就，前推后（翻译推理）
③ 占谁谁分母，每字后面做分母（资料分析）
④ 多几倍要−1，是几倍不用减（资料分析）
最终心法：行测文字题，不要按"谁在前谁大"的直觉走。
先找动词/介词，再定主被动，最后画箭头方向。
一个"于"字，就是一个反转信号。
