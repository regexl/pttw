行测资料分析｜公式+原理+高频易错点

一、增长量百化分估算误差原理

公式：增长量 = A/(1+r) × r，百化分：r=1/n，增长量≈A/(n+1)；下降量≈A/(n−1)

规律：增长率估大 → n估小 → 分母n+1偏小 → 估算增长量偏大

例：真实r=24.8%，当成25%（1/4，n=4）估算，算出增长量＞真实增长量。

增长率估小 → n估大 → 分母n+1偏大 → 估算增长量偏小

负增长（减少量）：|r|估大 → n估小 → n−1偏小 → 估算减少量偏大

二、分子分母同放缩（分数比较底层原理）

原理

比较两个分数，看分子增速、分母增速（相对变化率，不是绝对增量）

  • 分子增速＞分母增速 → 分数变大
  • 分子增速＜分母增速 → 分数变小

坑1：禁止用分子分母增加的绝对数值判断，必须是增长率！

坑2：仅适用于分子分母同增/同减；一增一减可直接秒杀：分子↑分母↓，分数变大；分子↓分母↑，分数变小。

关联知识点：两期比重判断（a＞b比重上升，本质就是分子增速＞分母增速）

三、核心公式汇总（极易混淆4组）

符号约定：A=分子现期，a=分子增速；B=分母现期，b=分母增速

考点名称 公式 题干识别关键词
基期比重 / 基期平均数 A/B × (1+b)/(1+a) 上一年的比重、上年平均XX
两期比重差 / 平均数增长量 A/B × (a−b)/(1+a) 比重上升/下降多少百分点；平均XX增加多少（带单位）
平均数增长率 (a−b)/(1+b) 平均XX同比增长百分之几（带%）

秒杀规则：两期比重差结果绝对值一定＜|a−b|，选项大于|a−b>直接排除。

一句话区分：百分点→比重差；%→平均数增长率；带单位差值→平均数增长量

四、间隔增长率

r间 = r₁ + r₂ + r₁r₂

  • r₁、r₂均＜10%：乘积项很小，可以忽略；忽略后结果偏小
  • 任意一个≥10%：乘积项不能省略

五、混合增长率（线段法）

口诀：混合增速，居中不正中，偏向基期量大的一方

线段距离之比 = 基期量反比；做题估算可以近似用现期代替基期。

六、年均增长率

(1+r)n = 末期 ÷ 初期

  • n = 年份差：普通时间段：末期−初期；五年规划：n固定=5，初期往前推一年
  • 近似公式：(1+r)n≈1+n·r，仅适合r＜5%；近似解出来的r偏大
  • 末期/初期固定，n越大，年均r越小；n固定，末期/初期越大，年均r越大
  • r＞5%不能用近似，优先代入选项验证

七、除法估算误差通用规则（直除）

分数 A/B

  • 分母估大 → 计算结果偏小；分母估小 → 计算结果偏大
  • 分子估大 → 计算结果偏大；分子估小 → 计算结果偏小

应用场景：基期量 A/(1+r)，r估大 → 分母1+r变大 → 估算基期偏小；r估小则基期偏大。

十、高频错误汇总

  1. 混淆平均数增长量、平均数增长率：看题干是%还是单位！
  2. 年均增长率年份差n算错；五年规划n=5，初期要往前推一年
  3. 分子分母同放缩，误用绝对增量对比，不是增长率对比
  4. 两期比重差，误选大于|a−b|的选项
  5. 百化分下降量公式：A/(n−1)，很多人继续用n+1
  6. 间隔增长率，两个增速都小于10%以外，漏算r₁r₂乘积项
  7. 估算误差方向搞反，题目问“偏大/偏小”判断失误

十一、解题逻辑总思路

  1. 读题干：识别问法，判断是基期、增长量、比重差、平均数增长率等；圈关键词（% / 百分点 / 单位）
  2. 定位数据，标记A、B、a、b
  3. 优先使用秒杀结论排除选项，不要一上来精算
  4. 估算时，预判误差方向，防止估算选反答案
  5. 最后剩余选项再少量计算
