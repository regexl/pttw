1增长量百化分估算误差原理

公式：增长量 = A/(1+r) × r，百化分：r=1/n，增长量 ≈ A/(n+1)；下降量 ≈ A/(n−1)

提示

规律：增长率估大 → n 估小 → 分母 n+1 偏小 → 估算增长量偏大

例：真实 r = 24.8%，当成 25%（1/4，n = 4）估算，算出增长量＞真实增长量。

增长率估小 → n 估大 → 分母 n+1 偏大 → 估算增长量偏小

注意

负增长（减少量）：|r| 估大 → n 估小 → n−1 偏小 → 估算减少量偏大

2分子分母同放缩（分数比较底层原理）

原理

比较两个分数，看分子增速、分母增速（相对变化率，不是绝对增量）

  • 分子增速＞分母增速 → 分数变大
  • 分子增速＜分母增速 → 分数变小
注意

坑 1：禁止用分子分母增加的绝对数值判断，必须是增长率！

坑 2：仅适用于分子分母同增/同减；一增一减可直接秒杀：分子↑分母↓，分数变大；分子↓分母↑，分数变小。

关联知识点：两期比重判断（a＞b 比重上升，本质就是分子增速＞分母增速）

3核心公式汇总（极易混淆 4 组）

符号约定：A = 分子现期，a = 分子增速；B = 分母现期，b = 分母增速

考点名称 公式 题干识别关键词
基期比重 / 基期平均数 A/B × (1+b)/(1+a) 上一年的比重、上年平均 XX
两期比重差 / 平均数增长量 A/B × (a−b)/(1+a) 比重上升/下降多少百分点；平均 XX 增加多少（带单位）
平均数增长率 (a−b)/(1+b) 平均 XX 同比增长百分之几（带 %）
注意

秒杀规则：两期比重差结果绝对值一定＜|a−b|，选项大于 |a−b| 直接排除。

一句话区分：百分点 → 比重差；% → 平均数增长率；带单位差值 → 平均数增长量

4间隔增长率

r间 = r₁ + r₂ + r₁r₂

  • r₁、r₂ 均＜10%：乘积项很小，可以忽略；忽略后结果偏小
  • 任意一个 ≥ 10%：乘积项不能省略

5混合增长率（线段法）

提示

口诀：混合增速，居中不正中，偏向基期量大的一方

线段距离之比 = 基期量反比；做题估算可以近似用现期代替基期。

深入学习
线段法口诀背后的严格数学推导（十字交叉、基期量与差值成反比）以及混合比重的等价结构见 → 第十二章

6年均增长率

(1+r)n = 末期 ÷ 初期

  • n = 年份差：普通时间段：末期 − 初期；五年规划：n 固定 = 5，初期往前推一年
  • 近似公式：(1+r)n ≈ 1+n·r，仅适合 r＜5%；近似解出来的 r 偏大
  • 末期/初期固定，n 越大，年均 r 越小；n 固定，末期/初期越大，年均 r 越大
  • r＞5% 不能用近似，优先代入选项验证

7除法估算误差通用规则（直除）

分数 A/B

  • 分母估大 → 计算结果偏小；分母估小 → 计算结果偏大
  • 分子估大 → 计算结果偏大；分子估小 → 计算结果偏小

应用场景：基期量 A/(1+r)，r 估大 → 分母 1+r 变大 → 估算基期偏小；r 估小则基期偏大。

10高频错误汇总

注意
  1. 混淆平均数增长量、平均数增长率：看题干是 % 还是单位！
  2. 年均增长率年份差 n 算错；五年规划 n=5，初期要往前推一年
  3. 分子分母同放缩，误用绝对增量对比，不是增长率对比
  4. 两期比重差，误选大于 |a−b| 的选项
  5. 百化分下降量公式：A/(n−1)，很多人继续用 n+1
  6. 间隔增长率，两个增速都小于 10% 以外，漏算 r₁r₂ 乘积项
  7. 估算误差方向搞反，题目问"偏大/偏小"判断失误

11解题逻辑总思路

  1. 读题干：识别问法，判断是基期、增长量、比重差、平均数增长率等；圈关键词（% / 百分点 / 单位）
  2. 定位数据，标记 A、B、a、b
  3. 优先使用秒杀结论排除选项，不要一上来精算
  4. 估算时，预判误差方向，防止估算选反答案
  5. 最后剩余选项再少量计算

12混合增长率 / 混合比重 · 严格推导

承接第五章
第五章线段法口诀"居中不正中，偏向基期量大的一方"给出了速算直觉；本章给出严格的数学推导与混合比重的等价结构。

一、混合增长率严格推导

设两部分：

部分 1：基期 A，增速 r₁；部分 2：基期 B，增速 r₂；整体混合增速 R

A(1+r₁) + B(1+r₂) = (A+B)(1+R)

展开化简得到核心等式：

A(r₁ − R) = B(R − r₂)
A / B = (R − r₂) / (r₁ − R)

二、十字交叉形式

A ： r₁ R−r₂ R B ： r₂ r₁−R

比例含义：基期量之比 = 增速差值之比

反比关系：体量越大，混合值离它越近，差值就越小。

三、混合比重（数学结构完全一致）

组 1 总量 A，比重 p₁；组 2 总量 B，比重 p₂；混合比重 P

A·p₁ + B·p₂ = P(A+B)
A(p₁ − P) = B(P − p₂)
A / B = (P − p₂) / (p₁ − P)

权重依旧是分母对应的真实基期总量。

四、行测易错警示

坑点：十字交叉得到的比值 ≠ 现期之比，是基期之比
只有粗略估算时，才可以用现期近似代替基期判断偏向；精算必须使用基期。

五、底层本质

混合增长率、混合比重本质都是加权平均数：权重为基期量；数学变形之后天然得到：权重和交叉差值成反比。

考场背诵口诀：
1. 混合 = 加权平均
2. 十字交叉：基期量之比 = 差值之比
3. 基数越大，离混合中心越近 → 量越大，差值越小，二者成反比
