1增长量百化分估算误差原理

公式：增长量 = A/(1+r) × r，百化分：r=1/n，增长量 ≈ A/(n+1)；下降量 ≈ A/(n−1)

提示

规律：增长率估大 → n 估小 → 分母 n+1 偏小 → 估算增长量偏大

例：真实 r = 24.8%，当成 25%（1/4，n = 4）估算，算出增长量＞真实增长量。

增长率估小 → n 估大 → 分母 n+1 偏大 → 估算增长量偏小

注意

负增长（减少量）：|r| 估大 → n 估小 → n−1 偏小 → 估算减少量偏大

2分子分母同放缩（分数比较底层原理）

原理

比较两个分数，看分子增速、分母增速（相对变化率，不是绝对增量）

  • 分子增速＞分母增速 → 分数变大
  • 分子增速＜分母增速 → 分数变小
注意

坑 1：禁止用分子分母增加的绝对数值判断，必须是增长率！

坑 2：仅适用于分子分母同增/同减；一增一减可直接秒杀：分子↑分母↓，分数变大；分子↓分母↑，分数变小。

关联知识点：两期比重判断（a＞b 比重上升，本质就是分子增速＞分母增速）

3核心公式汇总（极易混淆 4 组）

符号约定：A = 分子现期，a = 分子增速；B = 分母现期，b = 分母增速

考点名称 公式 题干识别关键词
基期比重 / 基期平均数 A/B × (1+b)/(1+a) 上一年的比重、上年平均 XX
两期比重差 / 平均数增长量 A/B × (a−b)/(1+a) 比重上升/下降多少百分点；平均 XX 增加多少（带单位）
平均数增长率 (a−b)/(1+b) 平均 XX 同比增长百分之几（带 %）
注意

秒杀规则：两期比重差结果绝对值一定＜|a−b|，选项大于 |a−b| 直接排除。

一句话区分：百分点 → 比重差；% → 平均数增长率；带单位差值 → 平均数增长量

4间隔增长率

r间 = r₁ + r₂ + r₁r₂

  • r₁、r₂ 均＜10%：乘积项很小，可以忽略；忽略后结果偏小
  • 任意一个 ≥ 10%：乘积项不能省略

5混合增长率（线段法）

提示

口诀：混合增速，居中不正中，偏向基期量大的一方

线段距离之比 = 基期量反比；做题估算可以近似用现期代替基期。

深入学习
线段法口诀背后的严格数学推导（十字交叉、基期量与差值成反比）以及混合比重的等价结构见 → 第十二章

6年均增长率

(1+r)n = 末期 ÷ 初期

  • n = 年份差：普通时间段：末期 − 初期；五年规划：n 固定 = 5，初期往前推一年
  • 近似公式：(1+r)n ≈ 1+n·r，仅适合 r＜5%；近似解出来的 r 偏大
  • 末期/初期固定，n 越大，年均 r 越小；n 固定，末期/初期越大，年均 r 越大
  • r＞5% 不能用近似，优先代入选项验证

7除法估算误差通用规则（直除）

分数 A/B

  • 分母估大 → 计算结果偏小；分母估小 → 计算结果偏大
  • 分子估大 → 计算结果偏大；分子估小 → 计算结果偏小

应用场景：基期量 A/(1+r)，r 估大 → 分母 1+r 变大 → 估算基期偏小；r 估小则基期偏大。

10高频错误汇总

注意
  1. 混淆平均数增长量、平均数增长率：看题干是 % 还是单位！
  2. 年均增长率年份差 n 算错；五年规划 n=5，初期要往前推一年
  3. 分子分母同放缩，误用绝对增量对比，不是增长率对比
  4. 两期比重差，误选大于 |a−b| 的选项
  5. 百化分下降量公式：A/(n−1)，很多人继续用 n+1
  6. 间隔增长率，两个增速都小于 10% 以外，漏算 r₁r₂ 乘积项
  7. 估算误差方向搞反，题目问"偏大/偏小"判断失误

11解题逻辑总思路

  1. 读题干：识别问法，判断是基期、增长量、比重差、平均数增长率等；圈关键词（% / 百分点 / 单位）
  2. 定位数据，标记 A、B、a、b
  3. 优先使用秒杀结论排除选项，不要一上来精算
  4. 估算时，预判误差方向，防止估算选反答案
  5. 最后剩余选项再少量计算

12混合增长率 / 混合比重 · 严格推导

承接第五章
第五章线段法口诀"居中不正中，偏向基期量大的一方"给出了速算直觉；本章给出严格的数学推导与混合比重的等价结构。

一、混合增长率严格推导

设两部分：

部分 1：基期 A，增速 r₁；部分 2：基期 B，增速 r₂；整体混合增速 R

A(1+r₁) + B(1+r₂) = (A+B)(1+R)

展开化简得到核心等式：

A(r₁ − R) = B(R − r₂)
A / B = (R − r₂) / (r₁ − R)

二、十字交叉形式

A ： r₁ R−r₂ R B ： r₂ r₁−R

比例含义：基期量之比 = 增速差值之比

反比关系：体量越大，混合值离它越近，差值就越小。

三、混合比重（数学结构完全一致）

组 1 总量 A，比重 p₁；组 2 总量 B，比重 p₂；混合比重 P

A·p₁ + B·p₂ = P(A+B)
A(p₁ − P) = B(P − p₂)
A / B = (P − p₂) / (p₁ − P)

权重依旧是分母对应的真实基期总量。

四、行测易错警示

坑点：十字交叉得到的比值 ≠ 现期之比，是基期之比
只有粗略估算时，才可以用现期近似代替基期判断偏向；精算必须使用基期。

五、底层本质

混合增长率、混合比重本质都是加权平均数：权重为基期量；数学变形之后天然得到：权重和交叉差值成反比。

考场背诵口诀：
1. 混合 = 加权平均
2. 十字交叉：基期量之比 = 差值之比
3. 基数越大，离混合中心越近 → 量越大，差值越小，二者成反比

13增长贡献率 / 拉动增长率 · 严格推导

本章定位
配合第三章「核心公式」与第十二章「混合加权」。本章给出"增长贡献率 / 拉动增长率"的严格定义 + 互推证明，并给出两个等价公式的考场速算优先级。

一、四个核心定义

设整体由若干部分组成，记：

  • 整体基期 = G₀，整体现期 = G₁，整体增量 ΔG = G₁ − G₀，整体增速 r = ΔG / G₀
  • 第 i 部分基期 = gᵢ₀，部分现期 = gᵢ₁，部分增量 Δgᵢ = gᵢ₁ − gᵢ₀，部分增速 rᵢ = Δgᵢ / gᵢ₀

两个核心定义：

  1. 增长贡献率 = 部分增量 ÷ 整体增量（结果单位 %，所有部分贡献率合计 = 100%）
  2. 拉动增长率（简称拉动增长）= 部分增量 ÷ 整体基期（结果单位 百分点，所有部分拉动增长合计 = 总增速）

二、两个等价公式（推导）

推导 ①：总增速 × 增长贡献率

拉动增长率 = 部分增量 / 整体基期
= (部分增量 / 整体增量) × (整体增量 / 整体基期)
= 增长贡献率 × 总增速

推导 ②：部分增速 × 基期比重

部分增量 = 部分基期 × 部分增速
拉动增长率 = (部分基期 × 部分增速) / 整体基期
= (部分基期 / 整体基期) × 部分增速
= 基期比重 × 部分增速

故有等价式（考场二选一）：

拉动增长率 = 总增速 × 增长贡献率 = 部分增速 × 基期比重

三、为什么是基期比重，不是现期比重

"比重"必须与"增速"在同一时点对齐。代入推导 ② 的分子展开：

部分增量 = 部分基期 × 部分增速
拉动增长率 = 部分增量 / 整体基期
= (部分基期 × 部分增速) / 整体基期
= (部分基期 / 整体基期) × 部分增速

比重项里出现的是部分基期 / 整体基期，这就是"基期比重"。

坑点：若错用现期比重，结果会偏离。
例：某部分现期比重 30%、基期比重 25%、总增速 10%、部分增速 14%：
· 用基期比重：25% × 14% = 3.5 百分点 ✔
· 用现期比重：30% × 14% = 4.2 百分点 ✘（差 0.7pp）

四、单位与合计（速判）

两个核心结论（合计验证）：

  • 增长贡献率之和 = 100%（每个部分贡献率即权重，权重相加为整体）
  • 拉动增长率之和 = 整体总增速（每个部分拉动即对总增量的分解）

若题目问"哪部分对增长的贡献最大"，比较贡献率；若问"哪部分拉动整体增长 X 个百分点"，比较拉动增长率。

五、考场速算优先级

优先级一：用「总增速 × 贡献率」—— 当贡献率或总增速已直接给出。
优先级二：用「部分增速 × 基期比重」—— 当基期比重直接给出。
优先级三：若基期比重未给，必须用现期比重近似；或退回"部分增量 ÷ 整体基期"严格计算。

六、底层逻辑（一句话）

增长贡献率 = 部分在"整体增量蛋糕"里切了多少；
拉动增长率 = 部分的增量在"整体基期池"里占了几分。
前者是相对总增量的占比（无单位，%）；后者是相对总基期的占比（百分点）。
两者通过"总增速"这座桥互通： 贡献率 × 总增速 = 拉动增长率。

14年均增长率 · 深度讲义

本章定位
第六章给出年均增长率的「公式 + 一句话原则」。本章展开严格推导 + 三大策略 + 4 道例题 + 比较题型 + 高频错误 + 解题流程图 + 速查表，对应国考 / 联考年均增长率全部题型，可单独成讲义复习。

14.1核心公式的本质推导

14.1.1 从逐年增长推导出公式

设基期量为 A，年均增长率为 r，经过 n 年后到达现期量 B。

第1年末：A × (1+r) 第2年末：A × (1+r) × (1+r) = A(1+r)² 第3年末：A(1+r)² × (1+r) = A(1+r)³ …… 第n年末：A(1+r)ⁿ = B
(1+r)ⁿ = 现期量 / 基期量
r = 年均增长率，n = 增长年份差（现期年 − 基期年）
本质：年均增长率就是"复利利率"。每年以上一年的总量为基数增长，而不是以最初的基期量为基数。这就是为什么不能用"总增长率÷n"。

14.1.2 为什么不能用"总增长率÷n"？

假设基期100，两年后变为144，总增长率44%。

❌ 错误：44% ÷ 2 = 22% ✅ 正确：(1+r)² = 1.44 → r = 20% 验证：100 →(+20%)→ 120 →(+20%)→ 144 ✓
用总增长率÷n算出来的值偏大，因为忽略了"利滚利"效应。

14.2二项式定理展开的完整推导

14.2.1 二项式定理

(a+b)ⁿ = Cₙ⁰aⁿ + Cₙ¹aⁿ⁻¹b + Cₙ²aⁿ⁻²b² + … + Cₙⁿbⁿ

令 a=1, b=r，代入得：

(1+r)ⁿ = 1 + nr + n(n-1)/2·r² + n(n-1)(n-2)/6·r³ + … + rⁿ

14.2.2 逐项分析（以 n=3 为例）

(1+r)³ = 1 + 3r + 3r² + r³
项表达式r=5% 时值占比
常数项11.00086.4%
一次项3r0.15013.0%
二次项3r²0.00750.65%
三次项r³0.0001250.01%
当 r 很小时（≤5%），二次项及以上贡献不到1%，可以忽略，因此 (1+r)ⁿ ≈ 1+nr。

14.2.3 近似公式的误差量化

rn=3 真实值1+nr 近似值绝对误差相对误差
1%1.0303011.030.00030.03%

r≤5%时误差<1%，资料分析选项通常差距≥5%，可放心用近似；r>5%时误差迅速放大，必须用不等式排除或精确代入。

14.2.4 不等式 (1+r)ⁿ > 1+nr 的严格证明

(1+r)ⁿ = 1 + nr + [Cₙ²r² + Cₙ³r³ + … + rⁿ] ↑ 每一项都 > 0（∵ r>0, n≥2） ∴ (1+r)ⁿ > 1+nr
用法：先用 1+nr 算出"偏小的估算值"，真实值一定比它大。若某选项代入 1+nr 后已≥现期/基期，那真实的 (1+r)ⁿ 只会更大，该选项必然偏大，直接排除。

14.3三大计算策略深度解析

策略① 居中代入法（选项差距大时）

Step1：计算 k = 现期/基期 Step2：取选项中间值 r₀，计算 (1+r₀)ⁿ Step3：(1+r₀)ⁿ > k → r₀偏大，选更小的；反之选更大的

策略② 近似公式法（r≤5%时）

(1+r)ⁿ ≈ 1+nr ⇒ r ≈ (k−1)/n
k = 现期/基期；算出来的 r 偏大，真实值略小一点点

策略③ 不等式排除法（r>5%且选项接近时）

【第一步·粗筛】用 1+nr 估算，排除明显偏大的选项 【第二步·精算】对剩余选项用二项式前三项 1 + nr + Cₙ²r² 精确计算，或直接代入验证

14.4典型例题精讲

例题1 · r≤5%，近似公式法
2018年某省GDP为3.5万亿元，2023年达到3.9万亿元。问2018-2023年该省GDP年均增长率约为？
A. 1.8%   B. 2.2%   C. 2.8%   D. 3.5%
n = 2023 − 2018 = 5
k = 3.9 / 3.5 ≈ 1.114
近似：r ≈ (1.114−1)/5 = 0.114/5 = 2.28%
真实值略小，最接近 B 选项
验证：(1.022)⁵ ≈ 1 + 5×0.022 + 10×0.022² = 1.1148 ≈ 1.114 ✓
答案：B. 2.2%
例题2 · 选项差距大，居中代入
某企业2015年营收2亿元，2020年营收5亿元。问2015-2020年年均增长率约为？
A. 15%   B. 20%   C. 25%   D. 30%
n = 5，k = 5/2 = 2.5
居中代入B选项20%：(1.2)⁵ = 2.488 ≈ 2.5 ✓
答案：B. 20%（背的常用数，(1.2)⁵≈2.488 几乎等于2.5）
例题3 · r>5%，选项接近，不等式排除
2016年某市常住人口1000万人，2021年达到1350万人。问年均增长率约为？
A. 5.8%   B. 6.2%   C. 6.7%   D. 7.1%
n = 5，k = 1350/1000 = 1.35
第一步（不等式粗筛）：用 1+5r 估算
r=6.2%：1+5×0.062 = 1.31 < 1.35，真实值>1.31，可能
r=5.8%：1+5×0.058 = 1.29 < 1.35，真实值>1.29，可能
两个都不能直接排除，需精算
第二步（二项式前三项精算）：
r=6.2%：1 + 5×0.062 + 10×0.062² = 1 + 0.31 + 0.0384 = 1.3484 ≈ 1.35 ✓
r=6.7%：1 + 5×0.067 + 10×0.067² = 1 + 0.335 + 0.0449 = 1.3799 > 1.35，偏大
答案：B. 6.2%
例题4 · 五年规划的基期确定（国考经典）
"十二五"期间（2011-2015年），我国某指标从2010年的500增长到2015年的800。问"十二五"期间年均增长率？
⚠️ 关键："十二五"期间的增长，基期是 2010年（前一年），不是2011年！
n = 2015 − 2010 = 5
k = 800/500 = 1.6
居中代入10%：(1.1)⁵ = 1.611 ≈ 1.6 ✓
答案：约 10%
基期规则总结：
• "2011-2015年"：基期2011，n=4
• "2011-2015这五年"：基期2010，n=5
• "十二五期间"：基期2010，n=5
• 题干说"从XX年到XX年"：基期是前一个年份

14.5年均增长率比较/排序题型

14.5.1 n 相同时：直接比比值

例题5 · n相同的比较
以下四个时间段（均为5年），某指标年均增速最快的是？
A. 从120增长到240   B. 从150增长到330
C. 从200增长到400   D. 从250增长到520
都是5年（n=5），直接比 现期/基期：
A：240/120 = 2.0   B：330/150 = 2.2
C：400/200 = 2.0   D：520/250 = 2.08
B最大
答案：B
秒杀技巧：n相同时，年均增速排序 = 现期/基期比值排序，完全不用开方！

14.5.2 n 不同时：不能直接比比值

例题6 · n不同的比较陷阱
甲：2010-2015年（5年），从100到180
乙：2012-2018年（6年），从100到210
谁的年均增速更快？
甲：(1+r甲)⁵ = 1.8，r甲 ≈ (1.8−1)/5 = 16%（近似），实际约12.5%
乙：(1+r乙)⁶ = 2.1，r乙 ≈ (2.1−1)/6 = 18.3%（近似），实际约13.2%
乙更快
答案：乙的年均增速更快
陷阱：n不同时，总增长率大的 ≠ 年均增速快，必须除以n（近似）或精确计算！

错误思路详细分析

错误1：手误把 n 算错
最常见的低级错误。比如"2016-2021年"，有人算成 n=6（2021−2016+1），实际上 n=5。
纠正：n = 现期年 − 基期年，不加1。增长了几年就是几。
错误2：近似公式算出后不验证
r≈(k−1)/n 算出来后直接选最接近的，但当 r 在5%边界附近时误差可能超过选项差距。

错误3：比较题想当然
看到"甲从100到200（翻1倍），乙从100到180（涨80%）"，就以为甲快，没注意n不同。
纠正：先看n是否相同，相同比比值，不同分别算。

15双基期增长率 vs 间隔增长率

本章定位
第四章给出「间隔增长率」的公式 + 一句话原则。本章以一道 2017 国考真题为蓝本，把双基期增长率（一个现期对比两个过去基期）和间隔增长率（连续两期顺推）放到一起对照，辨析两种极易混淆的「增长率反推」题型。

15.1原题呈现（2017 国考）

题目：2016 年末全国手持船舶订单较同年 2 月末（ ）。

A. 降低 16.2%    B. 降低 2.2%    C. 增加 16.2%    D. 增加 2.2%

材料：2017 年 1~2 月，全国造船完工 936 万载重吨，同比增长 123%；承接新船订单 221 万载重吨，同比增长 133%。2 月末，手持船舶订单 9207 万载重吨，同比下降 22.6%，比 2016 年末下降 7.6%。

正确答案：A

15.2本题题型：同现期·双基期增长率

15.2.1 考点识别

已知同一个现期时间点（2017 年 2 月末），分别对比两个不同基期（2016 年 2 月末、2016 年末）的增速，求两个基期之间的相对增长率。

15.2.2 符号定义

  • A：2017 年 2 月末（现期量，共同参照）
  • B：2016 年 2 月末（较早基期）
  • C：2016 年末（较晚基期）
  • rAB：A 相对于 B 的增长率 = −22.6%
  • rAC：A 相对于 C 的增长率 = −7.6%
  • rCB：C 相对于 B 的增长率（待求量）

15.2.3 公式完整推导

核心依据：增长率基本公式 现期 = 基期 × (1 + 增长率)

① 由同比下降22.6%得：
A = B × (1 + r_AB)

② 由比2016年末下降7.6%得：
A = C × (1 + r_AC)

③ 联立两式（左边均为A）：
B × (1 + r_AB) = C × (1 + r_AC)

④ 变形求两个基期的比值：
C / B = (1 + r_AB) / (1 + r_AC)

⑤ 代入增长率定义 r = 现期/基期 − 1：
r_CB = C/B − 1
r_CB = (1 + r_AB) / (1 + r_AC) − 1

15.2.4 代入计算过程

r_CB = (1 − 22.6%) / (1 − 7.6%) − 1
     = 0.774 / 0.924 − 1
     ≈ 0.838 − 1
     = −16.2%

结果为负，代表降低 16.2%。

15.3易混淆考点：间隔增长率

15.3.1 适用场景

时间线顺推：基期 → 中间期 → 现期，已知连续两期的增长率，求隔一期的总增长率（典型如"隔年增长率"）。

15.3.2 符号定义

  • A：最早期基期量
  • B：中间期量
  • C：最末期现期量
  • r₁：B 相对于 A 的增长率（第一期增速）
  • r₂：C 相对于 B 的增长率（第二期增速）
  • R：C 相对于 A 的间隔增长率（待求量）

15.3.3 公式完整推导

① 第一期增长：
B = A × (1 + r₁)

② 第二期增长：
C = B × (1 + r₂)

③ 将B代入，得到最终现期：
C = A × (1 + r₁)(1 + r₂)

④ 代入间隔增长率定义 R = C/A − 1：
R = (1 + r₁)(1 + r₂) − 1
  = 1 + r₁ + r₂ + r₁×r₂ − 1
  = r₁ + r₂ + r₁ × r₂

15.3.4 示例验证

2020 年产值 100 万，2021 年增长 10%，2022 年增长 20%，求 2022 年相对 2020 年的间隔增速。

R = 10% + 20% + 10% × 20% = 32%
验算：100 × 1.1 × 1.2 = 132，增长32%，公式成立。

15.4两大题型核心对比

题型 时间逻辑 核心公式 本质
双基期增长率（本题） 一个现期，回头对比两个过去基期 r = (1+r₁) / (1+r₂) − 1 逆向搭桥，求两个基期的相对变化
间隔增长率 连续两期增长，从过去顺推到现在 R = r₁ + r₂ + r₁×r₂ 顺向叠加，求两段增长的总效果

15.5高频错误与避坑指南

错误 1：直接将两个增速做减法

典型错解：−22.6% − (−7.6%) = −15%，近似选择 B 选项。

错误根源：直接相减是"增长量差值"的思维，但增长率是比例值，两个增速的基数不同，不能直接做减法，必须通过除法计算相对变化。

仅有的例外：当两个增速绝对值都极小（< 5%）时，直接相减误差可忽略；但增速较大时绝对不能使用。

错误 2：混淆两种公式的适用场景

把双基期题当成间隔增长率做，或反过来套用公式，导致结果完全错误。

快速区分口诀：

  • "连续涨、隔年算" → 间隔增长率：r₁ + r₂ + r₁r₂
  • "同现在、比俩过去" → 双基期：(1+r₁)/(1+r₂) − 1

15.6解题逻辑总结

  1. 定题型：先看时间关系，判断是"连续两期顺推"还是"一个现期对比两个基期"。
  2. 标增速：把每个增速对应的"现期-基期"时间节点写清楚，避免搞反方向。
  3. 带符号：下降/减少的增速必须带负号代入公式，不能漏掉负号。
  4. 判方向：先通过正负判断是增长还是降低，排除方向错误的选项。
  5. 估数值：结合选项差距估算，无需硬算精确值，节省时间。
第十五章心法：双基期 vs 间隔，看时间方向就能秒判：
· 时间线顺推（过去→现在）→ 间隔增长率，公式 r₁ + r₂ + r₁r₂；
· 时间线回看（现在回头比两个过去）→ 双基期，公式 (1+r₁)/(1+r₂) − 1。
与第四章的间隔增长率联读：第四章是公式 + 一句话原则，本章是真题复盘 + 易混点对照。
